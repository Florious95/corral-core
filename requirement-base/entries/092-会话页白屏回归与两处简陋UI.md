# 092 会话页白屏回归与两处简陋 UI

来源：用户 2026-08-21 对 `agentmirror-20260821-1324.apk` 的实测反馈（原话三条）。
用户总评：「做完最后的 app 体验非常不错」，但以下三条要修，第 1 条明令走回炉流程。

## §1 打开会话白屏（回归，走回炉流程）

用户原话：「打开会话体验回退，出现空白且不会出现对话界面。」

- 现象：从会话列表点开一个会话，页面空白，对话（终端）界面不出现。
- 定性：**回归**——上一版可以正常进入会话。引入区间 = 上一版验收 sha 到
  `agentmirror-20260821-1324.apk`（集成线 1f47c099 一带）之间 land 的 14 条 PR。
- 回炉铁律适用：改之前必须在模拟器亲眼复现（先红），回退定位引入 commit，
  审查席产出根因探针，修完探针不再命中 + 模拟器亲眼看到恢复。
- 高嫌疑区（仅供排查起点，不是结论）：本轮动过会话进入路径的 PR——
  e12-close / e13-new-pane / e1-resync / e2-composer / recon-foreground / geom-resume。

## §2 「+ Agent」弹窗 UI 过于简陋（优化）

用户原话：「+agent 的 ui 过于简陋。」

- 指工作区右上角 + 号开启 Agent 的界面（选 Provider、勾选 bypass 权限，088 §4）。
- 要求：与整体 UI 互洽、好看；参考成熟 Agent APP 的选择器/表单样式
  （088 已有的「图标要互洽、看了还想看」标准同样适用）。

## §3 设置里改 Provider 命令的界面也简陋（优化）

用户原话：「设置里面改命令后也是。」

- 指设置页里编辑每个 Provider 完整命令行的 UI（088 §5）。
- 同 §2 标准：排版、输入体验、视觉与全 app 一致。
- 解读注：按「也是=也简陋」理解；若用户实际指「改完命令后打开会话也白屏」，
  则并入 §1 复现矩阵（复现格需顺带验证：改命令后新开会话是否白屏）。

## §4 复现环境事实（leader 2026-08-21 铺路时确认，非缺陷）

- 模拟器 `agentmirror_test_b` 里旧安装的配对档案指向 `ws://10.0.2.2:22179/ws`
  （早前 e2e 的临时 daemon，已死），故一直「重连中」。这是陈旧配对，不是产品缺陷。
  复现时需 `pm clear` 后按 e2e/layer2.sh 的手填配对流程重配。
- 隔离环境搭法照抄 e2e/layer2.sh：隔离 TMUX_TMPDIR + 假 CLI 用
  `ln -s /bin/bash <dir>/claude`（cp 出来的 bash 会被 macOS 杀死跑不起来；
  shebang 脚本 comm 是 bash 不命中白名单，symlink 才能得到 comm=claude）。
- ⚠️ 测试 daemon 会扫到真实舰队的 tmux socket——⛔ 绝不许在 app 里点开真实会话，
  复现只许点自己隔离造的会话。
