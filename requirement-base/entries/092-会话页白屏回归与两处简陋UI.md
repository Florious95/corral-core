## §1 打开会话白屏（回归，走回炉流程）

用户原话：「打开会话体验回退，出现空白且不会出现对话界面。」

- 定性：**回归**——上一版可以正常进入会话。引入区间 = 上一版验收 sha 到
  `agentmirror-20260821-1324.apk`（集成线 1f47c099 一带）之间 land 的 14 条 PR。
- 回炉铁律适用：改之前必须在模拟器亲眼复现（先红），回退定位引入 commit，
  审查席产出根因探针，修完探针不再命中 + 模拟器亲眼看到恢复。
- 高嫌疑区（仅供排查起点，不是结论）：本轮动过会话进入路径的 PR——
  e12-close / e13-new-pane / e1-resync / e2-composer / recon-foreground / geom-resume。

## §9 probe16 定案（2026-08-21）：无 16s 定时器，残余黑屏是夹具造的不可能世界

- 实测（.team/nodes/hl1-probe16/说明.md）：订阅 8–10ms 发出；首帧 1794ms 到达、1798ms 已 replay
  （27B 含 marker，画上过）；「16s」= TermDrawMeter 15s 采样窗口的读数假象。
- 擦黑机理：app 视口 seed 在快照前 418ms 发 resize → SIGWINCH → 夹具 TUI（trap WINCH 只清屏不重绘）
  → 7B 清屏字节按 **delta** 到达 → 合法 delta 把主屏清掉。真实 CLI 清屏后会按新尺寸重绘，字形随 delta 回来。
- 裁定：「清屏后永不重绘」的 pane 在任何正确实现下都是黑的（宿主 attach 同黑）。
  verify2 夹具替换为三个真实世界：①真 claude CLI 空闲(alt=1) ②会重绘 TUI(trap WINCH 清屏+重绘)
  ③大滚回 hist；绿标准不变（冷点开 2s 内字形）。**此为判据语义修正非放宽**，理由如上记录在案。
- 遗留观察：首帧 1.8s（小内容）已接近 2s 门；大滚回 5.2s 未达门——若 ③ 仍红则立独立性能格
  （快照体量/分页策略），不改门。
