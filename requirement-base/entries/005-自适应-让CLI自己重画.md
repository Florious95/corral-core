# 005 宽高比自适应：让 CLI 自己重画，而不是客户端缩放

- 状态：已裁定（用户认可 leader 提案）
- 出处：leader 提案 + 用户认可，2026-08-09 对话

## 观点

终端内容是字符网格，**不可能像网页一样 reflow**。客户端缩放只有两种烂结果：字小到看不清，或横向滚动。
全世界唯一能正确重排终端内容的程序是 CLI 自己：TUI 天然响应式，收到 SIGWINCH 按新尺寸重画。
Claude Code 在 60 列窄终端里本来就画 60 列布局。

正解：手机打开会话时把手机行列数告诉 tmux（resize）→ CLI 重画 → 手机看到原生为手机比例渲染的界面。
"和 CLI 完全一致"由 CLI 本人保证。

## 已知代价与解法

tmux window 尺寸共享，手机 resize 会挤窄桌面画面。解法：`window-size latest` + grouped session
——谁最近在操作，尺寸听谁的。与真实场景吻合（用手机时人不在电脑前；回电脑一敲键盘尺寸自动回来）。

## 明确不支持

两端同时盯同一 pane 且尺寸不同——物理上无解，任何产品都一样，明确不支持。
