## §1 接入要求
- 按 assets/097-handoff/kotlin/session/接线说明.md 落地：文件拷入
  app/.../session/，接现有回调（onSendText/onPickAttachment/onKeyToken/onBack/onOpenViewMenu、
  受控 TextFieldValue）；terminalCanvas 插槽包现有 AndroidView(TermSurfaceView)，⛔ 不重写终端。
- 接线说明「问题清单」6 条由实现席逐条裁定并把裁定写进说明.md（如 onKeyToken 映射到现有
  按键协议；onSessionSelect 接会话切换；isRunning 接状态流）。
- adjustResize/imePadding、PredictiveBack 按说明落。

## §2 主题一致性（用户原话）
「我们已经做了对话页面的主题，我希望这个界面它的主题是完全一致的……我们底部的这个主题和
设置的 Agent 的对话的主题是不一致的。我希望在设置 Agent 的对话主题的时候，底部的主题也要
跟着变，并且整体是完全一致和自洽。」
- 要求：会话页 chrome（底部 dock/输入胶囊/按键条，及无顶栏后的全部壳层）配色从**当前选定的
  终端主题**（终端主题目录，浅槽/深槽）派生，⛔ 不再走与终端无关的固定 MaterialTheme 值；
  切换 Agent 对话主题时底部即时跟随，整页自洽。
- 交接件的 ConversationPageColors 映射表按此重定向：槽位 → 终端主题取色（背景/前景/强调），
  success/interrupt 扩展色也从主题派生或给出主题内近似。
- 验收：至少两套差异明显的终端主题下截图对照，底部与画布无「两张皮」观感。
