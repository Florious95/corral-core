# 002 两级分组模型：工作目录 → 会话

- 状态：已裁定（用户纠正过 leader 一次，见修订记录 R-001）
- 出处：用户裁定，2026-08-09 对话第二轮

## 观点

cwd 和 session 名**不是二选一的分组键，而是天然的两级结构**：

- **一级 = 工作目录（cwd）**：不同 session 名字各不相同，但 cwd 相同即归入同一工作空间。这一级是聚合出来的，key 就是 cwd。
- **二级 = 会话本身**：该目录下每一个 Agent CLI（tmux session/pane）是一个条目，点进去即终端镜像。

首页的"会话数"是按 cwd 聚合后的计数。扫描逻辑：枚举所有 tmux server（含私有 socket）
→ 取每个 pane 的 cwd → 按 cwd 归组。session 名只是二级列表的展示标签，不参与分组。
