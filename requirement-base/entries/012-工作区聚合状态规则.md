# 012 工作区聚合状态规则

- 状态：已裁定
- 出处：w-protocol-spec 政策请示 + leader 裁定，2026-08-09

## 观点

工作区（cwd 聚合，见 [[002]]）的聚合状态**由服务端权威计算，客户端只渲染**，客户端不做任何推导。

## 聚合规则

1. **取最高注意力优先级**：取 cwd 下所有会话中注意力优先级最高者的状态，优先级序：
   **blocked > done > working > idle**。
2. **unknown 不计入聚合**：unknown 会话不参与取最高，其自身仍显示 unknown——
   判不出就降级 unknown、绝不影响其余可用性，符合镜像/状态严格隔离（[[008]]）。
3. **全 unknown 才聚合 unknown**：仅当 cwd 下所有会话均 unknown，聚合结果才是 unknown。
4. **优先级语义 = 注意力需求排序**：优先级就是"agent 需要人注意的程度"排序
   （对齐 [[003]] 标准四"需要时被唤醒"）。今后新增状态按此原则插入优先级序，
   而非另行定序。

## 协议固化

聚合状态规则固化于 `docs/protocol.md` 协议正文（服务端下发、客户端渲染的数据契约），
不在客户端实现处散落。
