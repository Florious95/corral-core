## §2 🔴 主题必须与 Agent CLI 完全一致

**用户原话**：「我希望 APP 上看到的和 Agent 的 CLI 上看到的**主题是完全一致的**。
包括它的背景，各个对话的颜色等等。」

截图对照：
| | 背景 | 正文 |
|---|---|---|
| 主机 CLI（左） | **浅色**（近白） | 深色字 |
| APP（右） | **深蓝黑** | 浅色字 |

⇒ APP 把终端配色**写死成了深色**，没跟随主机终端的实际主题。
其余颜色（`查看` 的紫、`uiautomator dump` 的蓝、`Improvising…` 的粉、
`远控 leader` 的青底标签）两边**色相一致**，说明 ANSI 前景色通道是通的，
**坏的是背景/默认前景这一层**。

**这条的含义比"换个配色"大**：APP 是主机终端的镜像，
**镜子和实物不一致，用户就得在脑子里做一次换算**——这正是本产品要消灭的东西。

**🔴🔴 用户 2026-08-19 最终裁定：走 B —— APP 自带深/浅两套主题，自适应切换。**
（**推翻了同日稍早的 A「跟随主机」**，留档见本节末。）

**用户原话**：「我觉得还是改成 B 吧。那这样的话，手机 APP 它有深色和浅色，都能够自适应地去更换。
只不过说现在设计是浅色，然后你们现在投屏的是黑色。**我希望这个浅色就是我给你截图的这个样式。
我发的信息是灰底，然后整体是白底。不像现在整体是黑底，我发的信息是白底。**」

### 目标形态（浅色主题，以用户截图 `07-左侧遮挡与主题不一致.png` 的**左半边**为准）

| 元素 | 目标（浅色） | 现状（错的） |
|---|---|---|
| **终端整体背景** | **白底** | 深蓝黑底 |
| **正文字** | 深色 | 浅色 |
| **用户自己发的消息块** | **灰底** | **白底** |
| 其余 ANSI 前景色（紫/蓝/粉、青底标签等） | 保持，色相已经对 | —— |

🔴 **注意「整体白底 / 我发的消息灰底」这组关系现在是反的**——
不是「颜色深浅调一下」，是**底色的主次关系颠倒了**：
现在是深底上开一块白，目标是白底上开一块灰。判据要断言这组**相对关系**，
⛔ 不许只断言「背景是白的」——那样把消息块也刷成白的照样能变绿。

### 两套主题 + 自适应

- APP 自带 **深色 / 浅色** 两套完整主题，**跟随系统深浅色自动切换**。
- ⇒ **终端配色由 APP 的主题决定，不再取主机的值。**

### 这对「用 claude design 重做一份」的边界（B 之下重新划）

| 区域 | 归谁定 |
|---|---|
| 列表 / 收藏 / 设置 / 底部标签栏 / 「查看」浮层 / 会话页顶栏与输入条 | **设计全权** |
| **终端正文区**（`app/.../termview/`，自绘 Canvas） | **设计也全权**——定深/浅两套完整色板（背景、默认前景、ANSI 16 色、用户消息块底色、光标、选中）**＋度量规格**（字号 / 行高 / 字符网格 / 左右 padding） |

⚠️ 度量那部分比色板值钱：**§1 的左侧遮挡就是度量没定清楚造成的**。
⇒ B 之下终端区**完全进入设计范围**，这是 A/B 的实质差别。

**旧条 A（已作废，留档说明当时为什么那样立）**：
2026-08-19 稍早用户说「我希望 APP 上看到的和 Agent CLI 上看到的主题是完全一致的」，
leader 据此立了 A「跟随主机」：终端配色由主机数据决定，设计只定兜底色板与度量。
**推翻的成因**：用户真正要的是**「像我截图里那个浅色的样子」**，
而不是**「随主机变」**——「一致」指的是**目标外观**，不是**数据来源**。
🔴 教训：**用户说「要和 X 一样」时，先问清他要的是「长得一样」还是「跟着 X 变」。**
这两者的实现完全不同（一个是主题常量，一个是协议字段 + 传输面），
而在需求文字上完全同形。

**待查（⛔ 不猜，本轮要查清并写进说明）**：
- 终端自绘层（`termview/`）现在的颜色是从哪儿来的——硬编码常量？哪个文件？
- 「用户自己发的消息块」在渲染层怎么识别出来的（ANSI 背景色？还是 App 侧另外标的）？
  **这决定了「白底开灰块」能不能做出来。**
- Compose 的 `isSystemInDarkTheme()` 与自绘 SurfaceView 之间怎么联动。

**判据 `A-th-bg`**（B 之下重写）：
① **浅色模式下**：终端整体背景是**浅底**，**用户消息块是比它更深的灰**——
   断言这组**相对关系**（消息块底色 ≠ 整体底色，且更深）。
   🔴 ⛔ 不许只断言「背景是白的」：把消息块也刷成白的照样能让那条变绿，那是骗判据。
② **深色模式下**：关系反过来且仍然可辨（消息块底色 ≠ 整体底色）。
③ **切换系统深浅色，两套都生效**——断言切换前后终端背景**真的变了**。
   🔴 这条才是「自适应」的判据；只验一套等于没验自适应。
