# 006 秒开 + 历史滚动如原生

- 状态：已裁定（用户认可 leader 提案）
- 出处：leader 提案 + 用户认可，2026-08-09 对话

## 秒开

首帧快照：点击会话 → `capture-pane -e`（带颜色转义）抓当前屏先画上（目标 < 200ms）
→ 再订阅 `pipe-pane` 增量字节流接管实时更新。视频秒开的套路。

## 历史滚动

**把 scrollback 搬到本地**，绝不用 tmux copy-mode（每次滚动一次网络往返，必卡）：

- 打开时预取最近几百行历史（`capture-pane -S -N`），滚到边界按需分页再拉。
- 本地化后滚动即原生列表滚动——60fps、惯性、离线可滚，体验好于原生 CLI。
- 底部实时流追加时，滚上去看历史要锁定视口 + "回到底部"按钮（聊天 App 成熟交互）。

## 已知边界

走 alternate screen 的全屏 TUI 历史不进 tmux scrollback，只能镜像当前屏（降级）。
主流 agent CLI（Claude Code / Codex）是主屏 + scrollback 模式，主路径不受影响。

## 架构含义

手机端需要**真正的终端模拟器内核**（解析 ANSI 序列、维护网格、本地 scrollback buffer），
不是"显示文本的列表"。内核选型（原生引擎 vs WebView + xterm.js）是客户端最大技术决定，**尚未定夺**。
