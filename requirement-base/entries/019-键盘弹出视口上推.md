# 019 键盘弹出：视口上推，不触发重绘

- 状态：已裁定
- 类型：缺陷（用户真机实证，必修）D-20
- 出处：用户 2026-08-12 真机测试对话原话「我呼出输入框之后，它把整个 UI 给挡住了。它应该是往上顶…但是它不会让整个 UI 去重绘」「每多说一句话，整个界面都会重绘。重绘的结局那就是整个界面的变化、闪烁以及扭曲」

## 缺陷现象

呼出输入框后，键盘把整个 UI 挡住；每多说一句话整个界面都重绘 → 界面变化、闪烁、扭曲。

## 裁定行为

键盘弹出时**终端 rows/cols 不变**（不触发 tmux resize），但**视口要上推**——像聊天软件一样内容区平移，露出当前内容。当前实现是锁死不动，内容被键盘遮挡，错。

## 重绘规则（用户裁定）

「仅在第一次进入 CLI 时重排一次，此后都不再重绘」。
