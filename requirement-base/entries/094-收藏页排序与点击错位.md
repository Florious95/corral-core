# 094 收藏页排序与点击错位

来源：用户 2026-08-21 实测反馈（agentmirror-20260821-1324.apk）。

用户原话：「收藏页，我在装新 app 的次序，收藏页会变序，因为运行的更加靠前，点开始终都基于旧的次序，首先收藏不变序，此外点进去不是外面标题的对话，这个问题也要解决」

## 两条要求

1. **收藏页不变序**：收藏页列表**不做**「运行中靠前」的动态重排，保持稳定次序
   （收藏时的次序）。「运行中在前」的排序规则只属于会话页（088 排序契约），
   收藏页不适用——收藏是用户手工圈定的集合，位置稳定性优先。
2. **点击错位必须修**：现状是列表显示上重排了，但点击命中的还是旧次序的条目
   ⇒ 点开的会话和行标题不是同一个。**根因大概率是列表项按位置/索引绑定而非按
   会话身份绑定**（Compose items 无 key / 记忆了旧索引一类）。修复必须按身份绑定，
   ⛔ 不许只把「显示排序」关掉来掩盖绑定错位（那是症状遮掩：绑定错位在会话页
   一样会咬人——会话页是合法动态重排的，绑定必须在任何重排下都正确）。

## 验收要点
- 先验红单测：① 收藏页排序稳定性（运行状态变化不改变次序）；
  ② 点击绑定正确性（任意重排后，点击行 N 打开的会话 id == 行 N 展示的会话 id，
  会话页与收藏页两处都断言）。
- 模拟器复验：收藏两个会话（一运行一空闲），切换运行状态后逐行点开核对标题一致。
