# 042 上传图片路径不应填充输入框

- 状态：已裁定（本轮缺陷，需修复）
- 类型：缺陷 D-30
- 出处：用户 2026-08-12 原话「你上传之后，你这个图片就附着在输入框的上部就行了，它发的时候就自动发过去，不需要填充输入框，导致你输入不方便」

## 缺陷现象

上传图片后，文件路径（如 /Users/.../upload-xxx.jpg）被填进输入框，影响后续输入。

## 裁定行为

图片上传后应**附着在输入框上方作为预览/附件标记**，发送时自动带上，**不填入输入框文本**。
