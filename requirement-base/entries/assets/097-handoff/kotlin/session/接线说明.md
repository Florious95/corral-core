# 与现有 SessionScreen.kt 的接线说明

目标目录：`app/app/src/main/java/dev/agentmirror/app/session/`（本包内文件直接拷入）。

## 参数 → 现有回调
- `onSendText` / `onPickAttachment` / `onKeyToken` / `onBack` / `onOpenViewMenu`：签名与你们现有一致，直传。
- `value` / `onValueChange`：受控 `TextFieldValue`，直接接现有输入状态。发送成功后请在宿主里 `onValueChange(TextFieldValue(""))` 并（可选）`LocalFocusManager.clearFocus()` —— 收焦点即触发输入胶囊收回单行动画。
- `terminalCanvas = { AndroidView(factory = { TermSurfaceView(it) }, ...) }`：插槽占满中间区域，本代码不触碰内容。
- `dockMode: DockRowMode` + `onDockModeChange`：新增的 UI 状态，建议放你们现有的 UiState（默认 `DockRowMode.Sessions`）。
- `sessions: List<SessionChipUi>` + `onSessionSelect(id)`：**新增回调**，点击块即切换终端所属会话。

## 需要你们做的环境事项
- Activity/window：`adjustResize`（或 `WindowCompat.setDecorFitsSystemWindows(window,false)` + 现有 inset 方案），`imePadding()` 才能把 dock 顶起（对应设计稿的键盘推起动画）。
- 系统返回：无顶栏，返回全靠边缘手势 → `onBack` 接 PredictiveBackHandler / OnBackPressedDispatcher。
- 色值映射见 `SessionScreenScaffold.kt` 头部 ConversationPageColors 表；`success`（运行中状态点）与 `interrupt`（Ctrl-C）建议做扩展色，代码里临时占位为 `tertiary` / `error`。

## 问题清单（我没猜，等你们定）
1. `onKeyToken` 的 token 协议：我用了 `"Esc"/"Tab"/"Up"/"Down"/"Left"/"Right"/"Ctrl-C"`（表在 HotkeyRow.kt 顶部，改一处即可）。你们现有是 ANSI 序列还是语义名？
2. `onSessionSelect(id)` 不在你们给的回调清单里——现有 SessionScreen 是否已有会话切换入口？没有的话这个签名可以吗？
3. 会话块的 `isRunning` 数据源：从你们的 shell 状态流取，还是先不显示状态点？
4. 「查看」弹出菜单锚点：`onOpenViewMenu()` 无参。若你们的原生菜单需要锚点 View/offset，告知形态我再加参数。
5. 浅色主题色值是从截图取样的近似值（表中已标注），发送蓝 `#2456e6` 映射 `primary` 是否与你们浅色主题现值冲突？
6. `expandedLines` 默认 3，是否要暴露为远端配置？

## 动画对照（HTML → Compose）
- 行三态切换 rowIn（fade+上滑 6px）→ `AnimatedVisibility(fadeIn+slideInVertically)`
- 输入框 1→3 行膨胀（height .25s）→ `animateDpAsState(tween(250))`
- 胶囊描边聚焦高亮 → `animateColorAsState(tween(200))`
- 虚拟键盘推起 → 交系统 IME + `imePadding()`，无自绘键盘。
