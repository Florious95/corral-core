# 090 · 连接生命周期两条（E17 回归 / E18 收藏页不重连）

- 日期：2026-08-21
- 来源：用户实测两条
- 关联：[082 收藏页跨工作区在线判定失真]

## 1. E17（回归）· 会话页回前台不重连

用户原话：「如果说我在一个对话页面进入了后台，就是把这个程序 APP 放入了后台，
我再回来的时候，**它是不会尝试重连的**，**这属于改动引发，因为之前可以**，
我必须退出去再进来才可以。」

- **失败条件 F-090-1**：会话页在屏、APP 从后台回到前台、连接已断 ⇒ **没有发起重连尝试**。

### 🔴 2026-08-21 用户补充：是**概率性**的，不是必然

用户原话：「它确实，它**不是完全不会不刷，它有概率不刷**，然后刷的时候的话，
**它的比例有可能是错的**。」

⇒ **F-090-1 的判据必须能捕捉概率性失败**：⛔ 跑一次绿不算数。
必须**重复 N 次**（或注入时序扰动）并断言 **N 次全部触发**；
一次都没漏才算修好。只跑一次的判据在概率性缺陷上**恒有假绿**。
- 🔴 **是回归** ⇒ 必须先用 `git log -S` / `git log -p` 定位**哪一次改动去掉了它**，
  把 commit sha 写进说明；找不到就明写「查不清」，⛔ 不许编一个说得通的因果。

## 2. E18 · 收藏页不进入重连

用户原话：「我在收藏页，它不会进入重新连接的状态。就说收藏页，
**它就必须点进去，它才发现自己没连上，然后才开始重连**。」

- **失败条件 F-090-2**：停在收藏页、连接已断 ⇒ 收藏页自己不发起重连，
  必须点进会话才开始。

## 2.5 E19（新）· 回前台重排出的几何比例是错的

同一次操作的**另一个症状**：回到前台后终端**刷了，但比例错**——
用户截图里字号明显过大、右侧内容被切掉。

- **失败条件 F-090-4**：APP 回到前台后重排，得到的几何（列数 / 行数 / 字号 / cell 尺寸）
  **与真实视口不符**。
- ⚠️ 这条**不属于「重连」**，属于**视口几何**（`termview/`），与 F-090-1/2 不同源，
  ⛔ 不许混在一格里修——混了就分不清「重连修好了」还是「几何修好了」。
- 关联既有事实：`SessionRoute.INITIAL_COLS = 120` 曾被查明是「进页重排」的根因；
  `ViewportGeomStore` 是几何的持有者。
- 🔴 **诊断日志纪律（083 实发教训）**：`onViewportSizeChanged` / `onRealViewportChanged` /
  `viewportOutgrewEmulator` 此前**零记录**，导致「回前台后终端只画了上面三分之一」拿着诊断日志诊断不了。
  本条必须把**参与比较的两边的原始数值**都记下来，例：
  `viewportOutgrewEmulator: viewport_rows=42 emulator_rows=17 → true`，并记**触发来源**。

### 判据
- `A-geom-resume`：模拟「会话页 → 后台 → 回前台」，断言重排后的几何**等于**真实视口算出的几何。
  🔴 **重复 N 次全绿才算过**（同 §1 的概率性要求）。先验红。
- `A-geom-log`：断言上述三个回调**各产出一条含两边原始数值的记录**。⛔ 不许只写「未触发」。

## 3. 🔴 同一个形状的第三次 —— 必须修在共同入口

上一轮修过「指示灯不实时 ＋ 查看菜单空」，根因是**会话页在屏时未订阅当前工作区**。
E18 是同一回事换了个页面。

⇒ **必须在「可见性变化」的共同入口上修，⛔ 不许再给收藏页单独补一个订阅。**
否则下一个页面还会坏，而且下一次仍然只会在用户实测时才暴露。

- **失败条件 F-090-3**：修复后两条路径**不是同一个入口**（即又给收藏页补了一份）。

## 4. 验收判据

- `A-recon-fg`：模拟「会话页 → 后台 → 回前台」且连接已断，断言**真的发起了一次重连尝试**。
  🔴 断言的是发起了重连，⛔ 不是「某个状态变量被设了」。先验红。
- `A-recon-fav`：模拟「停在收藏页 ＋ 连接已断」，断言**收藏页自己进入重连**，⛔ 不需要点进会话。先验红。
- `A-recon-once`：断言两条路径**走同一个入口**（同一函数被调用）。这条防的是 F-090-3。
- user gate：用户真机复现两条场景确认已修。

## 5. 诊断日志要求

凡有守卫/阈值/比较的地方，**把参与比较的两边的原始数值都记下来**再记结论，
并记**触发来源**（可见性 / 网络 / 用户操作）。
⛔ 不许只写「未触发」——「压根没被调用」「被调用但守卫拦下」「守卫算错了」三种在日志里同形。
