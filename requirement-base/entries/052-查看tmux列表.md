# 052 查看 tmux 列表

- 状态：已裁定（新功能，**本轮不施工**）
- 类型：功能 F-06
- 出处：用户 2026-08-12 原话「加一个查看当前 tmux 列表的功能」「tmux 列表也就是 ctrl+b 再按 w 的列表」

## 裁定行为

在 App 里查看 `Ctrl+B w` 的**完整树形列表**——所有 tmux session 下的所有 window，带**实时状态自动刷新**（能看到 window name 后面的工作状态动态效果如 braille spinner）。
