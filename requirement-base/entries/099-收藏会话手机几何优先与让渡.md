# 099 收藏会话手机几何优先与活动让渡（用户裁定，取代 098 的 linger 议题）

用户原话（2026-08-22）：「手机存在在线的时候，只要手机连上，那就第一时间把所有的窗格调整到
手机的样式。也仅限于收藏。同时手机不在会话页面、在电脑端发送了一个消息，那我就将电脑端的
画面展示为完全。」

## 规则
1. **手机连上（配对连接建立）⇒ 立即把【收藏的】会话 pane 调整为手机几何**。非收藏 pane 不动。
2. **让渡**：手机当前不在该会话页面，且电脑端产生了输入活动 ⇒ 该 pane 恢复电脑端完整几何。
3. 手机点开会话页 ⇒（若已被让渡）再调回手机几何——因几何多数时候已就位，打开≈零 resize。

## 设计细节（实现席裁定并写说明，契约只定边界）
- 「电脑端发送了消息」信号：必须区分【人在电脑端输入】与【Agent 自己吐输出】——
  候选：tmux client_activity（有 attach 的真实 client 且其 activity 前进）/ pane 输入流来源。
  ⛔ 不许把 Agent 输出当电脑活动（否则运行中的收藏永远被让渡）。
- 防抖/滞回：连接抖动、电脑偶发一键不许引起几何来回翻，规定最小保持窗口。
- 与 pane_geometry restore 契约的关系：本条是其显式例外集（收藏+手机在线），
  restore 逻辑对收藏 pane 的行为按本契约改写。

## 已裁定不做
- 「缓存旧帧秒显+更新中标注」：用户否决（2026-08-22）。理由：操控工具里对过期画面下指令有危险。
