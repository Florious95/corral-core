# 003 对话体验的四条验收标准

- 状态：已裁定（用户认可 leader 提案）
- 出处：leader 提案 + 用户"上面你说的我认可"，2026-08-09 对话

## 四标准

1. **输入零延迟**：输入框是本地的，打字/改字/输入法联想全程不走网络；按发送那一刻整条消息经
   `send-keys` 一次性注入并回车。与 SSH 逐键转发范式的本质区别——逐键转发在手机上必然是灾难。
2. **发送必达**：注入后有回执（确认字节已进 pane），失败明确报错，不允许"发出去了没反应"。
3. **状态零丢失**：事实源在主机 tmux，链路只是投影。WiFi 切蜂窝、App 被杀、隧道闪断，
   重连后重放当前屏幕即完全恢复。不存在"消息丢了"这个概念。
4. **需要时被唤醒**：手机场景不是盯屏，是"agent 需要我时叫我"。状态解析层检测到
   blocked（等输入）/ done 即推送通知。对舰队用户这条是体验的皮，前三条是骨。

## 附加输入能力

- 图片附件：手机上传 → 主机落盘 → 把文件路径注入 CLI 输入（Claude Code 等 CLI 原生吃图片路径），
  不涉及任何多模态 API。
