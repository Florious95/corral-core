# 030 开发+测试同步派单，红测先行

- 状态：已裁定
- 类型：工程体系 / 流程 P-01
- 出处：用户 2026-08-12 原话「你在派活的时候，就应该同步的派测试去做…让开发自己去走测试开发循环，直到红测消失」

## 裁定行为

派开发席时**同步派测试席**。测试席先写**红测**（failing test），开发席改完跑红测到绿。**不能开发自己说通过就通过**。
