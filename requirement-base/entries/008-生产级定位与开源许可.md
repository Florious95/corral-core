# 008 生产级定位、状态解析、开源许可

- 状态：已裁定
- 出处：用户裁定，2026-08-09 对话第三轮

## 裁定

1. **不是 MVP，是生产可用的完整产品。**
2. **状态解析（working / idle / blocked / done）是必做项**，不是可选增强。
3. **Apache 2.0 全开源，不盈利，毫无保留。** herdr 也是 Apache 2.0——它对本项目不只是参照，
   是可直接研读复用的知识库（它已解决"从进程和终端输出判定 15+ 种 agent 状态"这个最脏的活）。
   按其许可规则合规使用：保留版权声明与 LICENSE、标注修改。
4. 背景判断：**未来是多 Agent 时代**。现有产品都是单 agent 陪伴式假设，
   面向舰队的产品形态（聚合视图、按工程导航、状态一屏尽收）是空位。

## 架构约束：镜像层与状态层的不对称

- 终端镜像零适配——任何 CLI 天然支持，永不因 CLI 升级而坏。
- 状态解析必然 per-agent——每种 CLI 一份判定规则，CLI 改版可能失效。
- **两层严格隔离**：状态判不出降级为"未知"，绝不影响镜像与输入的可用性。
