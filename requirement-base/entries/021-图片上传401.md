# 021 图片上传 HTTP 401 必现

- 状态：已裁定
- 类型：缺陷（用户真机实证，必修）D-22
- 出处：leader 草稿，2026-08-12（用户真机测试必现）

## 缺陷现象

图片上传永远失败，HTTP 401。`fix-upload-bearer` 已加 Bearer 头，但**运行时 token 传递链路断裂**（头加了、token 没传进去）。

## 修复方向

图片上传请求必须带上运行时可用的认证 token，修复 Bearer 传递链路。
