# 027 服务端自动发现

- 状态：已裁定（新需求，**只入库不施工**——见 [[037]] W-03）
- 类型：功能 F-01
- 出处：用户 2026-08-12 原话「TS 填写之后，直接进入局域网，直接加载整个局域网里面所有主机可能的服务端」「假设也不填 TS Token，它首先就应该根据局域网去查找可能的服务端，并且要将它的延迟展示出来」

## 裁定行为

1. **不填任何东西**：App 打开即扫局域网，发现所有运行 agentmirrord 的主机，列出并显示延迟。
2. **填了 TS auth key**：发现范围扩大到 tailnet。
3. **点选主机**：地址自动填入，只需填 token 或扫码确认。
