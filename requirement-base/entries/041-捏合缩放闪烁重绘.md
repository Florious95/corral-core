# 041 捏合缩放时闪烁重绘

- 状态：已裁定（本轮优化，改动成本合理则做）
- 类型：缺陷 D-29
- 出处：用户 2026-08-12 真机实测

## 缺陷现象

捏合缩放过程中屏幕不断闪烁重绘，不流畅。

## 原因

捏合手势连续触发 onZoom → 每次重算 rows/cols → 每次发 resize → tmux 每次重排 + snapshot 回传，造成连续闪烁。

## 优化方向

捏合过程中只做**本地视觉缩放**（CSS transform 或 Canvas scale），手指松开后才算最终 rows/cols 发一次 resize。即「捏合时预览，松手时生效」。
