# 033 Web 端复刻（测试优先）

- 状态：已裁定
- 类型：工程体系 / 流程 P-04
- 出处：用户 2026-08-12 原话「这个安卓 APP 能不能复刻出一个 Web 端？在 Web 端的测试它会更方便」

## 裁定行为

基于**同一 WebSocket 协议**，用 **xterm.js** 做一个 Web 版客户端。**主要用于测试**（Playwright 比 adb+uiautomator 快一个量级），80% 的问题可以在 Web 端先规避。

## 定位

Web 端是**测试载体**，不是产品形态本身；协议必须与安卓端同源，才能保证「Web 端绿 = 安卓端逻辑绿」。
