# 016 生产级验收定义修正

- 状态：已裁定
- 出处：用户回炉裁定，2026-08-09
- 修订：修正 [[015]]"验收达成"的判据（见 REVISIONS R-003）

## a) 生产级验收 = 真机首触零阻断

用户真实手机走完**首触清单**，全程无阻断、失败必有明确报错：

扫码配对 → 工作区列表 → 打开会话 → CLI 画面一致 → 输入回显 → 发图注入 →
blocked 通知 → 杀 App 恢复 → 锁屏重连。

## b) 必要非充分

自动化测试与门禁是**必要非充分**条件；**最终验收权在用户真机**（[[013]] 是支撑，非替代）。

## c) 覆盖偏差教训

可自动化程度**不得决定覆盖优先级**；用户首触路径必须**最先最重**覆盖。

## d) 未验证清单

无人值守环境缺真机时，未经真机验证的路径必须显式列入**「未验证清单」交付用户**，
禁止计入"已验收"。
