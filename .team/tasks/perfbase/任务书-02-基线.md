# 任务书 02 · 模拟器性能基线测定（任务二）

必读：`docs/交接任务书-性能基线与仓库重构.md` 任务二节；本文是它的可执行化。
**前提**：任务一仪表已过异源评审。被测物 = 仪表版服务端（隔离端口，⛔ 不碰 9900）+ 仪表版 APP。

## 用户令（写死，这是本任务存在的理由）

> 此后任何改动**不允许低于**这个基线；优化**必须高于**这个基线。

所以基线的价值全在**可信**：样本够、环境同、取数纯。**⛔ 极端值不许剔除**——单独列进 outliers
并附当次完整日志段与怀疑原因。剔掉极端值的基线是假地板，比没有基线更坏。

## 硬约束（用户原话）

- **⛔ 不能识图、不能取帧、不能取帧间隔**。数只能来自 `adb logcat -s PerfTrace`。
- ⛔ 绝不点开真实舰队会话（测试 daemon 会扫真实舰队，只许点你自己造的夹具 pane）。
- ⛔ 不碰 9900 生产 daemon；自己的 daemon 另起端口、`AGENTMIRROR_STATE_DIR` 另指。
- 隔离 tmux **必须自检在自己的 socket 上**：短路径 + 预建目录 + `unset TMUX` +
  `tmux -S <sock> list-sessions` 自检；**建 socket 失败时 tmux 会静默回退到用户真实 tmux**，
  自检不过立刻停手上报。参照 `e2e/layer2.sh`。
- 假 CLI 用 `ln -s /bin/bash <dir>/claude`（⛔ `cp` 的 bash 起不来；shebang 会让 comm=bash 漏白名单）。
- ⛔ 不写 /tmp 之外……更正：⛔ 不写 /tmp，临时件写 `.team/nodes/pb-emu/tmp/`；
  隔离 tmux 的 socket 目录允许用 `/tmp/e2e-pb-emu`（短路径硬要求），仅此一例。

## 资源前置（先看再起，不达标就如实报不可判）

模拟器 `agentmirror_test_b`；`emulator` 与 `adb` 在 `~/Library/Android/sdk/`（**不在 PATH，用全路径**）。
起之前看 `vm_stat` 的 free+inactive 与 `uptime` 的 load。**内存不够或 load 过高 ⇒ report 不可判，
⛔ 不许硬起把机器拖垮**（本机曾出现 free 只剩 59MB、load 29）。
模拟器无头启动可能被崩溃同意弹窗挡住：`rm -f /tmp/android-alauda/emu-crash-*.db` 后重试。
截图/取屏之前先 `adb shell input keyevent 111`（本链不取屏，只取日志）。

## 三个夹具（各自一个 tmux pane，⛔ 不用「清屏后永不重绘」夹具——092 §9 定案的不可能世界）

| key | 内容 |
|---|---|
| `real_claude_idle` | 真 `claude` CLI 空闲态（alt=1） |
| `redraw_tui` | 会重绘的 TUI：`trap WINCH` 清屏后**重绘**内容 |
| `big_scrollback` | 大滚回：`seq 40000` |

## 流程

1. 起隔离 daemon（仪表版 server，隔离端口 + 隔离 state dir），起模拟器，装仪表版 APK。
2. `pm clear` 后手填配对，连上隔离 daemon。
3. 每夹具 **冷点开 ≥10 次**：每次 `am force-stop` 重启 app → 点开该夹具会话 → 等排布完成。
   点击用 uiautomator 语义定位，⛔ 不用坐标硬敲。
4. **只从 `adb logcat -s PerfTrace` 取数**，按 `open_id` 归并出 8 个时间戳。
5. 统计每夹具的 `first_draw`（tap→first_draw）与 `layout_settled`（tap→layout_settled）：
   `mean` `p50` `p95` `max`。**极端值不剔除**，另列 outliers。

## 交付物

`.team/perf/baseline-<YYYYMMDD>.json`，形状（判据 `tools/perfbase/judge-baseline.sh` 逐项核）：

```json
{
  "baseline_date": "2026-08-22",
  "app_sha": "<仪表版 commit>", "server_sha": "<同>",
  "apk_md5": "<md5>", "emulator": "agentmirror_test_b / <系统镜像>",
  "fixtures": {
    "real_claude_idle": {
      "samples": [
        {"open_id": "ab12", "t": {"tap": 0, "route_enter": 12, "subscribe_sent": 20,
          "geom_seed": 25, "first_frame_recv": 180, "snapshot_applied": 190,
          "first_draw": 210, "layout_settled": 730}, "note": ""}
      ],
      "stats": {"first_draw": {"mean": 0, "p50": 0, "p95": 0, "max": 0},
                "layout_settled": {"mean": 0, "p50": 0, "p95": 0, "max": 0}},
      "outliers": [{"open_id": "zz99", "reason": "<怀疑原因>", "raw_log_path": ".team/perf/raw/<文件>"}]
    },
    "redraw_tui": {...}, "big_scrollback": {...}
  }
}
```

- `t` 里八个键**必须齐且单调不减**，缺一个就算不出分段 ⇒ 判据判红。
- 原始 logcat 段落落 `.team/perf/raw/`，⛔ 不许只留统计结果。
- `.team/nodes/pb-emu/说明.md`：环境自证（socket 自检输出、夹具 pane 的 `ps -o comm=`、
  daemon 端口与 state dir、模拟器资源读数），以及**你没做到的部分如实写**。
- report_result status = `done`；环境不具备 ⇒ 如实报，⛔ 不许编数。
