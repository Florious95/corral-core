## 做了什么

独立协议 `overlay_subscribe` / `overlay_unsubscribe` / `overlay_frame`，与 `level2_*` 分订。

- 打开才订阅：0→1 才 `Start` 专用客户端（只 `attach-session -t am-overlay`）。
- 关掉即停：最后一名退订立刻 `Stop`，零订阅者零抓屏、零客户端。
- 有订阅时 100ms `refresh-client` + 读 PTY；哈希未变不推。
- 只动 scratch pane 标题做转圈（不往用户 pane 发按键）。
- 抓屏实现放在 `internal/overlay`，避免踩 `TestLevel2NoTmuxAttach` 对 `api/` 的禁 attach 扫。
