## ① A-rf-l1 — 红（必红）

无人订阅二级时 `new-session radd` 窗口 `rf-added`（白名单 grok comm），立刻再发 `list`：

```

list2 count=1 names=["rf-keep","count=1"]
```

`handleList` → `ensureInitialScan`：快照已在就直接 `currentSnapshot()`，不重扫。这是 §2 定位的一级根因。

## ② A-rf-l2 — 绿

退订 → 改标题 `⠋ now working - grok` → 再 `level2_subscribe`：

```
l2 first dt_ms=53 status=working n=2 title="⠋ now working - grok"
PASS ② 首帧 working 且 dt=53ms < 2000
```

「无人订阅时改世界再进入」走的是 0→1，`markLevel2` 会唤醒。当前服务端这条是通的。
App「离开不退订、回来不重订阅」是另一条路径，不在本条字面里；本探针按契约 ② 的「无人订阅 → 进入」测，不把它改红。
