# t.port 安卓 OverlayEmulator

契约：066 附则 + 065。参照 `web/js/overlay.js` OverlayEmulator。

## 做了什么

- 新增 `dev.agentmirror.app.overlay.OverlayEmulator`：备用屏/CUP/ED/EL/SGR，CSI 不当字形。
- `SessionViewModel.applyOverlayFrame`：每帧 `resize` 清空再 `feed`，再 `dropScratchLines`。不追加。
- 单测 `OverlayEmulatorFixtureTest`：读 `.team/nodes/ov2-probe/frames.jsonl`（若无则用 `src/test/resources/overlay/frames.min.jsonl` 8 帧），逐帧喂真实模拟器，断言 ①无裸控制序列 ②目标会话在、scratch 不在 ③行数 ≤ rows、同一 `├─` 行不重复。

## 为何不用三级 TerminalEmulator

065 曾要求复用三级路径；加强探针在现行 App 上仍红（CSI 当文本、行数 251）。066 附则改为移植 web 那层专用缓冲。每帧整屏替换是 overlay_frame 的语义，与三级增量 feed 不是同一条路。

## 夹具

t.probe2 的真夹具到位后走 probe 路径；解析兼容 `{text,rows,cols}` 与 `{payload:{...}}`。目标名在常见集合里按原文命中选取，避免夹具会话名一换就红。
