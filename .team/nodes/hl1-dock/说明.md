## 问题清单裁定=

1. `onKeyToken`：交接语义名 `"Esc"/"Tab"/"Up"/"Down"/"Left"/"Right"/"Ctrl-C"`。线上协议是 `InputKey`（wire `esc`/`tab`/`up`/…/`ctrl_c`）。宿主 `dockKeyTokenToInputKey` 映射，不改 keys 帧。
2. `onSessionSelect(id)`：接既有 `onOpenOverlaySession`（`id`=`ref`）。签名保留。
3. `isRunning`：overlay `L2Status.WORKING`；`statusName` 带 Busy/Idle/Unknown。空 overlay 用当前 `name` 合成一块。
4. `onOpenViewMenu()`：无参。直调 `viewModel.openOverlay()`（`SessionSwitchSheet` 不需锚点）。
5. 浅色发送蓝 `#2456e6`：不钉取样。`primary` 从当前 Scheme ANSI 蓝/紫或 cursor 现算。
6. `expandedLines`：默认 3，不暴露远端配置。焦点膨胀在 `CommandInputBar`（E2）。

## 主题派生说明=

`conversationColorScheme` ← `TermPalette.of(dark)`（当前浅/深槽目录源文件）：

| chrome 槽 | 终端主题 |
|---|---|
| background | defaultBg（与画布纸色同一来源） |
| surface / surfaceContainer* | 纸色朝 defaultFg 抬档 |
| surfaceVariant | userBlockBg |
| onBackground / onSurface | defaultFg |
| outline / outlineVariant | 纸↔字插值 |
| primary | ANSI 4/12/5 或 cursor（相对纸 luma 差 ≥ 48） |
| primaryContainer | selection，否则 primary 溶进纸色 |
| error（Ctrl-C） | ANSI 1/9 |
| tertiary（运行点） | ANSI 2/10 |

不读 `appLightScheme`/`appDarkScheme` 固定值。087/089 测试未删。
