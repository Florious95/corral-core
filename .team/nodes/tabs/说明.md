# t.tabs 底部标签栏

## 做了什么

067 §4.1 已推翻「滑动三页」：滑动没有可见入口，用户找不到收藏。

`ThreePaneHome` 加 Material3 `NavigationBar`：底部三个标签 **收藏 / 会话 / 设置**，默认选中「会话」。点标签切页。`HorizontalPager` 滑动保留为附加手势，不再是唯一入口。

收藏本身（点星 → 实心 → 左栏出现 → 点进会话、离线置灰不可进）没改。

## 一眼能看见收藏在哪

冷启动落在「会话」工作区列表时，底部已经有「收藏」二字，不用滑、不用猜。

## 单测

配套测试名含 `BottomTabs`：`app/app/src/test/kotlin/dev/agentmirror/app/BottomTabsTest.kt`

- 会话页不滑也能看见三个标签
- 点「收藏」切到收藏页
- 点「设置」切到设置页
- 冷启动落在「会话」（不是收藏空页）

`./gradlew -q testDebugUnitTest --tests '*BottomTabs*'` 在仓根与 worktree 均已绿。

为让 `onNodeWithText("收藏")` / `onNodeWithText("设置")` 在「标题+标签」双节点下不炸，只动了 `TestThreePane`（改用 tag）和 `PairingUxTest`（`onAllNodesWithText("设置").onFirst()`）。
