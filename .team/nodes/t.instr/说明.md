# t.instr · 按键回显量具

席位：`in-dev`（输入透传席）。worktree：`.worktrees/wt-instr`。

## 怎么跑

```
cd .worktrees/wt-instr
# 需要在线模拟器。load1>15 时脚本不新起模拟器（本轮用已在线的 emulator-5554）。
bash tools/perfbase/keyecho.sh 30
sh tools/perfbase/judge-keyecho.sh
```

脚本做的事：隔离 tmux（sink=`/bin/cat`，见下「白名单门面」）+ 隔离 daemon（高端口，本轮 `0.0.0.0:19917`，⛔ 不是 9900）+ 安装 debug APK + 手填配对 + 进 `keyecho_cat` 会话 + 逐字符 `adb shell input text a–z` + 从 `adb logcat -s PerfTrace` 按 `(seq,char)` 配对 `key_send`/`key_echo`。

输出：

- `.team/perf/keyecho-<时间戳>.json` 与 `.team/perf/keyecho-baseline.json`
- 原始 logcat：`.team/nodes/t.instr/tmp/keyecho-<时间戳>.logcat`（⛔ 不写 `.team/perf/raw/`）

Unix socket 短路径例外：`mktemp -d /tmp/e2e-ke.XXXXXX`（worktree 路径超 unix socket ~104 字节；目录 0700）。daemon 只扫 `AGENTMIRROR_E2E_DISCOVERY_SOCKET_DIRS`，不扫用户真实 `/tmp/tmux-<uid>`。

## 打点（只加仪表，关时零成本）

- `key_send`：`PerfTrace.keySend`，仅单字符 `a`–`z`；调用点 `if (ConnPerf.isEnabled())`。
- `key_echo`：`TerminalEmulator.print` 在 `onAsciiPrint != null` 时回调（`core-terminal/.../TerminalEmulator.kt:224-228`）；`TermSurfaceView.onDraw` 里 `if (PerfTrace.isEnabled()) flushKeyEchoAfterDraw`。
- `SessionViewModel` init：仅 `PerfTrace.isEnabled()` 时挂 `emulator.onAsciiPrint`。
- 关路径：挂钩为 null，print 多一次空引用判断，不分配。

## 产品白名单门面（显式，不是静默改任务）

任务要求 sink=`cat`。产品 `filterModel` 按进程 comm 白名单丢掉非 Agent CLI（`server/internal/api/whitelist.go:43-64`），裸 `exec cat` 时 listing `cur_sessions=0`，App 列表「暂无工作区」。

量具做法：`ln -sfn /bin/cat $TMP/bin/claude` + `PATH` 前置后 `exec claude`。`ps comm=` 为 `claude`（白名单命中），**进程仍是 /bin/cat，一对一回吐**。未改产品码。对照 e2e「假 CLI ln -s …/claude」。

## 这把量具量不到什么

- **鼠标 / SGR 点击**（没有 click_send/click_echo）。
- **网络抖动作为独立序列**：本格路径是模拟器 `10.0.2.2` → 本机 daemon loopback。p50 含这段 RTT，但**拆不出**「纯网络」vs「绘制」。真机蜂窝中转要另采。
- **IME 组合期 / 非 a–z / 多字符一次上屏**：`keySend` 对 `char.length != 1` 不发事件（避免配错对）。
- **打开会话链**（tap…first_draw）：故意不碰。
- **shell 提示符重绘**：sink 不是 shell。

3. `listing: first snapshot` 是 debug 级；等待改用 info 级 `listing: refresh on open`。
4. token 框 dump 只见 `••••`，不能按明文搜 TOKEN。
