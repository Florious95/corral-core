## 做了什么

`classifyPaneTitle` 不再用一张 ◐/✳ 闭表把其余一律判 unknown。共享层只做三态兜底；每个 Agent CLI 一个探测器文件，init 注册。

### 文件

| 文件 | 职责 |
| --- | --- |
| `server/internal/api/detect.go` | 注册表 + 兜底。无前导符号 ⇒ idle；有符号无人认领 ⇒ unknown。**无 CLI 字面量**（账本 `A-s-decoupled` 认 `detect*.go`） |
| `server/internal/api/l2detect_claudecode.go` | ◐◓◑◒ → working；✳ → idle |
| `server/internal/api/l2detect_grok.go` | U+2800–U+28FF / ` - Thinking - ` / ` - Waiting for response` → working；无前导符号且以 ` - grok` 结尾 → idle |
| `server/internal/api/level2.go` | 删掉写死符号常量，调用共享层 |

接新 CLI = 新增一个探测器文件 + 一个测试文件，不改共享层、不改别的探测器。

### 判定

1. 探测器认领 → 用其 status（known=true）
2. 空 / 全空白 / 首个非空白是 Letter 或 Number → `idle`
3. 否则 `unknown`，日志同时写 `codepoint=U+XXXX`、完整 `title`、以及 `is_letter` / `is_number` / `leading_glyph` 操作数

禁止用摘要正文判活。Grok 空闲标题会留下上次任务摘要；只有精确标记 ` - Thinking - ` / ` - Waiting for response` 才是工作态。
