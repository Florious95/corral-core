# 068 白名单探针：红在哪几条

- 探针：`probe-wl.sh`
- 现场：隔离 socket `/tmp/wl-advisor/tmux/sock`（`list-sessions` = `wlfix`），未碰用户 default
- 当前产品：二级列表收录 **所有** pane，无 provider 字段，无 comm 白名单

## 夹具备注（显式：启动方式补了一刀）

五个文件按任务写成 `exec sleep 600`。本机直接跑脚本后 comm 是 `sleep`，脚本名消失。
启动改为 `exec -a $BIN/<name> sleep 600`，`ps -o pid=,ppid=,comm=` 得到全路径，例如
`/tmp/wl-advisor/bin/codex`。否则 ①③ 在实现之后也会因 comm≠家名而假红。

现场 pane（标题全是主机名，`#{pane_current_command}` 全是 `sleep`——印证 068 表：标题和 current_command 都不能当依据）：

```
w-claude  cmd=sleep title=MacBook-Pro.local
w-codex   cmd=sleep title=MacBook-Pro.local
w-copilot cmd=sleep title=MacBook-Pro.local
w-grok    cmd=sleep title=MacBook-Pro.local
w-cursor  cmd=sleep title=MacBook-Pro.local
w-bare    cmd=sleep title=MacBook-Pro.local
codex_comm=/tmp/wl-advisor/bin/codex
```
