### 行列换算

`col = floor(xPx / cellWidth) + 1`，`row = floor(yPx / cellHeight) + 1`，钳在网格内。
字格来自 presenter 已实测的 `cellWidth`/`cellHeight`（不是把像素当列）。
测例：cell 10×20 px、点 (40,40) → 第 5 列第 3 行。

### 节流 / 去重

- **cell-motion**：只在 `crossedCell()` 为真时上报（同格 MOVE 零帧）。整数比较，无分配、无 IO。
- **跟踪开着**（DOWN 的 `encodeMouse` 非 null 并发出）：本指针不再进 `GestureDetector`，避免一次滑动既发 1002 又发滚轮。
- **跟踪关着**：`onTermMouse` 返回 false，手势仍走既有 `onRemoteScrollBy` → `ScrollWheelFrame`（50ms 节流未改）。
- 不在 touch 回调里 `String.format` / 网络以外的事；`sendRawBytes` 是既有发送路径。

## tmux `mouse` 怎么验证没在截获（本格未执行）

契约 §1：外层 tmux 截获鼠标 ⇒ 点击永远到不了内层 Agent。**这一格不改 tmux 配置**，
也 **⛔ 不碰用户真实 tmux**。下面命令给用户/leader 在**跑 Agent CLI 的那台主机、隔离 socket**上执行。

检查（期望 `off` 或空）：

```
tmux -S <sock> show-options -g mouse
tmux -S <sock> show-options -s mouse
tmux -S <sock> show-options -w mouse
```

如果开着，应关掉（全局 / 会话 / 窗口三级）：

```
tmux -S <sock> set-option -g mouse off
tmux -S <sock> set-option -s mouse off
tmux -S <sock> set-option -w mouse off
```

对照：`mouse on` 时同一点击会切窗格、Agent 无反应；`off` 时点折叠行应由 Agent 重绘。

本格未对任何 socket 跑上述命令，也未假设它已经是关的。
