# 任务书 · t.step4 · APP 壳：采集鼠标/触摸事件与修饰键（输入透传第 4 步）

## 一、目标与验收

**产品目标**：所有键盘操作与鼠标点击对被投影的 Agent 界面**完全生效**；
**鼠标归内层 Agent**——点击要落到 Agent TUI 的可折叠区域（「点一个工具调用能展开看它调了什么」），
⛔ 不是给 tmux 切窗格。

**最终验收是用户真机**，⛔ 不是量具。**性能是最核心的体验，不许回退。**

**前三步已完成（都已并线，⛔ 不必重做）**：
- 第 1 步：服务端能收裸字节（`server/internal/bridge/inject_raw.go`，可打印 `-l` / 控制 `-H`，调用次数有界）
- 第 2 步：客户端能表达裸字节（`InputFrame.bytes: ByteArray?`，base64，缺省省略该键）
- 第 3 步：核层跟踪鼠标模式 + SGR1006 编码（1-based；1003 降级为 1002 并留痕）

**这一格是最后一块拼图**：壳把用户的手指/鼠标动作**采集**出来交给核层编码。

## 二、要做什么

在 `app/app/`（壳）里采集事件并送出去：

1. **采集**：终端视图上的按下 / 抬起 / 拖动（cell-motion 粒度）→ **换算成行列**（1-based）。
   行列换算要用**当前网格的字符宽高**，⛔ 不许用像素直接当列。
2. **修饰键**：Ctrl / Alt / Shift 状态要带上（SGR 的 Cb 位里有它们的位）。
   ⛔ 壳只**采集**修饰键状态，**编码是核层的事**（第 3 步已实现）。
3. **交给核层编码，把返回的字节走第 2 步的 `InputFrame.bytes` 发出去。**
   ⛔ 壳不许自己拼 CSI 字节——那会把编码规则复制成两份。
4. **对面没开鼠标上报时不发**（核层第 3 步的编码入口已经返回「不发」，壳要正确处理这个返回，
   ⛔ 不许发空帧）。
5. **滑动映射成滚轮**（契约 §3：1002 下不靠 1003 的像素移动流）。
   已有 `ScrollWheelFrame` 语义，⛔ 优先复用它，不要新造一套。

⛔ **这一格不许做的**：
- ⛔ 不改核层编码（第 3 步已完成）、⛔ 不改协议（第 2 步已完成）、⛔ 不改服务端
- ⛔ 不做预测性本地回显（第 5 步）
- ⛔ 不改 tmux 侧的鼠标配置——⚠️ 见下方「必须写进说明的一条」

## 三、⚠️ 必须写进说明的一条（契约 §1 的推论）

## 四、复现先红
