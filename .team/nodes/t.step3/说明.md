### 模式状态存在哪

活状态在 `TerminalEmulator` 私有成员 `mouse: MouseModeTracker`（`TerminalEmulator.kt:60`）：

- 协议组当前值：`mouse.tracking` → 公开 `mouseTrackingMode`（0 / 1000 / 1002）
- 编码组当前值：`mouse.encoding` → 公开 `mouseEncodingMode`（0 / 1006；若对面最后设了 1005/1015 则记下该码，但 `canEncode()` 仍为 false）
- 到达顺序：`mouse.snapshotOrder()` → 公开 `mouseModeOrder: List<MouseModeEvent>`（码 + 开/关）
- 降级留痕：`mouse.lastDowngradeTrace` → 公开 `lastMouseDowngradeTrace`

组内互斥、后设覆盖（xterm.js 同类）：`1000h` 再 `1002h` → 1002；只开 1000 **不**升 1002。

## 热路径开销怎么保证是常数的

- **跟踪不在每字节上跑。** `AnsiParser.feed` 仍是每字节 `consume`（既有）；鼠标账本只在 CSI
  完成、`prefix=='?'` 且 final 为 `h`/`l` 时，经既有 `setPrivateMode` 调一次
  `mouse.apply`（`TerminalEmulator.kt:296-297,:351-352`）。
- `apply`：几次 `==` 整数比较 + 可选往 `IntArray` 追加一个 packed int。
  无 HashMap、无每字节 map 查找、无每字节分配。
- 顺序缓冲预分配 16 槽，满了才 `copyOf`（CSI 完成时偶发，不是每字节）。
- 编码路径（点击）才分配 `ByteArray`；那不是解析热路径。

## 任务书那串 `\e[<0;5;3M`：核对过，没有写错

对照 xterm ctlseqs / 契约 §2：`CSI < Pb ; Px ; Py M`，Pb=0 左键，**Px=列、Py=行，1-based**。
「第 3 行第 5 列」→ Px=5、Py=3 → `\e[<0;5;3M`。
