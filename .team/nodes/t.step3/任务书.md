# 任务书 · t.step3 · core-terminal：跟踪鼠标模式并把点击编成字节（输入透传第 3 步）

## 一、目标与验收（⛔ 别自己发明标准）

**产品目标**：让所有键盘操作与鼠标点击对被投影的 Agent 界面**完全生效**。
**鼠标归内层 Agent**（用户 2026-08-23 裁定）——点击要落到 Agent TUI 的可折叠区域上
（「点一个工具调用能展开看它到底调了什么、改了什么代码」），⛔ 不是给 tmux 切窗格。

**最终验收是用户真机**，⛔ 不是任何量具的绿。**性能是最核心的体验，不许回退。**

**为什么这一步必须动核**：点击编成什么字节，**取决于对面那个 Agent 开了哪个模式开关**
（`\e[?1002h` / `\e[?1006h`），而那个开关**只有终端仿真器在解析输出流时看得到**。
壳做不了，服务端也做不了。

## 二、这一格要做什么（两件，⛔ 不多做）

### A. 跟踪模式（解析输出流）

在 `app/core-terminal` 的 VT 解析里**记录对面 app 设过的鼠标相关 DEC 私有模式**：

- **协议组**：1000（按下/抬起）、1002（cell-motion）、1003（any-motion）
- **编码组**：1006（SGR）、1015、1005
- 每个模式要记 **码、开/关状态、到达顺序**（第 4 节重连重放要用；这一格先把状态记全）。

**裁定（出自 `docs/输入透传契约.md` §3，⛔ 不许放宽）**：
- 对面请求 **1003 ⇒ 核层降级为 1002**，并**留痕两边操作数**（`requested=1003 enabled=1002`）。
  ⛔ 降级没留痕 = 线上只看到「鼠标怪」，分不清是对面要了 1003 被降了还是我们没开 1002。
- 只有 1000 不够（拖选/按住滑动要 1002），但**对面只开 1000 时我们不许自作主张升到 1002**——
  如实按对面开的算。

### B. 编码（把一次点击变成字节）

给核层一个**纯函数**式的编码入口：输入（事件类型、按钮、行列、修饰键），输出字节序列。

**裁定（契约 §2，⛔ 不许放宽）**：
- **只用 SGR 1006**：按下 `CSI < Cb ; Cx ; Cy M`，抬起同形但结尾 `m`。**纯 ASCII 十进制。**
- ⛔ **不用 X10 / 1005 / 1015**。X10 把坐标塞进单字节 `32+coord`，超过 223 列就废，
  UTF-8 下实测卡在 127（xterm.js #1962）。
- **坐标 1-based**（终端惯例），⛔ 不是 0-based。写清你用的是哪种并测它。
- **对面没开鼠标上报时，编码入口必须返回「不发」**，⛔ 不许硬发一串没人要的字节。

⛔ **这一格不许做的**：
- ⛔ 不碰 APP 壳的事件采集（第 4 步）
- ⛔ 不碰预测回显 / ack 节奏（第 5 步）
- ⛔ 不碰滚轮映射的 UI 侧（`ScrollWheelFrame` 已有语义，这一格只在编码层对齐，不改 UI）
- ⛔ 不改服务端

## 三、复现先红

先写红测再改实现：

- **R1**：喂一段含 `\e[?1002h` `\e[?1006h` 的输出流给仿真器，断言**模式状态被记下来了**
  （1002 开、1006 开）。改前必须红。
- **R2**：在「1002+1006 已开」状态下，编码一次「左键按下于第 3 行第 5 列」，
  断言字节**逐字节等于** `\e[<0;5;3M`（⛔ 自己核对 Cb 与行列次序，别照抄我这串——
  **如果我写错了，以 xterm 规范为准并在说明里指出我写错了**）。改前必须红。
- **R3**：对面请求 **1003** 时，断言**实际启用的是 1002**，且**留痕里同时有 1003 与 1002**。改前红。
- **R4**：对面**没开**任何鼠标模式时，编码入口返回「不发」。改前红或不适用，写清哪种。

**把改前的红原文贴进说明。**

## 四、性能（⛔ 两层，别在这里设门）

- 这一格改的是**终端仿真的解析路径**——那是热路径（每个字节都过）。
  所以：**模式跟踪必须是常数开销**，⛔ 不许每字节做分配、⛔ 不许每字节走 map 查找。
  在说明里写清你的实现是怎么保证这一点的。
- **粗筛**：`app/gradlew :core-terminal:test --rerun-tasks` 跑通（判据会自己跑）。
  ⚠️ 跑任何测量前先 `sh tools/perfbase/envcheck.sh --gate`。
- **最终判据是用户真机**，由 leader 打包给用户实测。⛔ 你不许设性能门。
