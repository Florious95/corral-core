## 做了什么

Rust crate `tools/nodeprobe/` + 包装 `tools/nodeprobe.sh`。

输入 `-S <socket 路径>` 或 `-L <名字>`，只跑 `tmux list-panes -a -F`（不 attach、不 send-keys、不改 pane）。每个 pane 用与 Go `classifyPaneTitle` 同一套 062 规则扫 `#{pane_title}`。

附加 `nodeprobe fixtures [titles.tsv]`：逐行输出 `state<TAB>provider`，给 `probe-np.sh` 用。

### 判定

| 标题 | state | provider |
| --- | --- | --- |
| Claude `◐◓◑◒` | working | claude_code |
| Claude `✳` | idle | claude_code |
| Grok 盲文 U+2800–U+28FF，或含 ` - Thinking - ` / ` - Waiting for response` | working | grok |
| 无前导符号且以 ` - grok` 结尾 | idle | grok |
| 无前导符号（字母/数字/空） | idle | unknown |
| 有前导符号、无人认领 | **unknown**（不回落 idle） | unknown |

unknown 的 `evidence` 必带 `glyph` / `codepoint=U+XXXX` / 完整 `title`。

`provider` 只来自标题能否认；认不出就是 unknown，不从进程名猜。

`pane_tty` 上 `ps -t … -o comm=` 的 basename 只进 `evidence.comms`，不得推翻标题的 working，也不得把 unknown 改成 idle。

不在 tmux 下的节点不在范围：本工具只枚举该 socket 的 pane，不会去扫 tmux 外进程。

### 禁读 argv

`src/` 里没有 `ps aux` / `pgrep -f` / `/proc/*/cmdline` / `args()` / `cmdline`。CLI 用 `args_os()`；子进程只用重复 `.arg()`，不用 `.args()`。
