## cols 上限依据

参考真机 1260px、density 3：旧几何（外 8 + 内 14）约 **112 列**。padding 减量后若不封顶会涨到 ~120 列，Claude Code Tips 会切双栏。112 钉在改前的列数。

CJK 占 2 格。4.5 寸（~360dp，内容宽 340dp）上格宽 ≈ 3.0dp、CJK ≈ 6.1dp（density 3 时 18px），仍盖得住 t.clip 实测 11–13px 左溢。⛔ 不再把内 padding 往 6dp 下调。

## §8 选型

选①矢量折线，不选 baseline offset。字符 `‹` 换字体/语言会再失准；折线关于盒子垂直中心对称。

## §9 白名单（有意保留与框架默认同值）

浅色 `onPrimary` / `onSecondary` / `onTertiary` / `onError` = 白（`AppPalette.onAccent`）；`surfaceContainerLowest` = 纯白（最底层卡片）。设计就是这些值，与 M3 默认碰巧相同，列入白名单而不是微调糊弄。

未覆盖、设计没给对应色的槽：Material3 后续可能再加的 `*Fixed` / `*FixedDim` 系列——本 BOM 的 `ColorScheme` 构造器未暴露则未写。再冒紫色弹窗会被 `ConsoleChromeSchemeEveryMaterial3SlotDiffersFromFrameworkDefault` 拦住。
