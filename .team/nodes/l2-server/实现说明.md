## 做了什么

按方案 §2–§3 落地服务端二级列表。身份只用 tmux 结构字段；状态只看 `pane_title` 第一个 Unicode 标量；认不出就是 `unknown`，绝不回落 `idle`。

### 数据源

- 复用 `discovery.Discover`（`list-panes -a -F`），不 attach。
- `ref` = `socket + \x1f + pane_id`；`name` = `window_name`（空则 `session_name`）；`cwd` = `pane_current_path`；`title` = `#{pane_title}` 原样。

### 符号表

| 符号 | 码点 | status |
| --- | --- | --- |
| `◐` | U+25D0 | working |
| `✳` | U+2733 | idle |
| 其它 / 空标题 | — | unknown |

未知日志同时写 `codepoint=U+XXXX`（大写十六进制）和完整 `title=`。只写「符号未知」不算。

### 时效

- 轮询 2s；0→1 订阅立刻 wake。
- 相对该连接上次快照有变更才推 `level2_frame`（seq++）。
- 无变更满 8s 推 `level2_heartbeat`（seq++，无 sessions）。
- 零订阅者：park，一次 `Discover` 都不调（interval 醒来后先复核计数）。

### 协议

- `Session.status`：只许 `working` / `idle` / `unknown`（`omitempty`，一级 listing 不带）。
- `level2_subscribe` / `level2_unsubscribe` / `level2_frame` / `level2_heartbeat`。
- subscribe 的 `workspace` 必须非空。
