# t.web 悬浮窗 web MVP

契约：`requirement-base/entries/066-悬浮窗先在外部端做MVP与展示要求.md`（并 065）。  
账本：`ledger.overlay-fix.v1` revision 5。仓根 `web/` 施工。

## 怎么走真实流

会话页右上角「查看」→ `Client.subscribeOverlay(sessionSocketFromRef(ref))` 发出 `overlay_subscribe`（socket = ref 里 U+001F 前的 tmux 结构前缀）。  
服务端回 `overlay_frame`；`App.applyOverlayFrame` 把 `text` 喂进 `OverlayEmulator`（解释备用屏/清屏/SGR），`pre.textContent` **整屏替换**。关掉发 `overlay_unsubscribe`。

服务端对照：`go test ./internal/api -run 'TestOverlayHonorsRequestedSocket|TestOverlayExcludesScratchSession'` 绿（真实 WS + 隔离 tmux + overlay_subscribe/overlay_frame）。

隔离 tmux：`/tmp/ov2-web/sock`，`list-sessions` 自检 = `alpha-ov2` / `中文目录`。默认 socket 不含 `中文目录`（DEFAULT_HAS_ZH=0）。测完 `kill-server`。

## ① 简洁样式（无裸控制序列）

渲染后扫描备用屏/擦行/字符集复位等字面量：**空**。可见树线与会话名，没有观测装置字面量。

```
(0) - 中文目录: 2 windows
├─ 0:docs-说明
│  ◒ working  docs/说明.md
└─ 1:claude-mix
   ◐ idle
(1) - alpha-ov2: 1 windows
└─ 0:working
```

`dropScratchLines` 去掉 `am-overlay` / `ov-spin` / `tree*` / `sleep*`。

## ② 中文 / 中英混排

`HAS_ZH=true`：`中文目录`、`docs-说明`、`docs/说明.md` 同时在渲染结果里，无 U+FFFD。等宽网格里 CJK 按双宽占格。

## ③ 树全部展开

上树同时有 `docs-说明` 与 `claude-mix` 两窗，客户端不折叠。行数 7。

## ④ 动态工作 / 停止

连续 8 帧转圈字符：`✳◐◑◒✳◐◑◒`（活）。`working` 与 `idle` 同屏。顶栏转圈 CSS 在工作态转、停止态停。

## 替换不是追加

`LINE_SERIES=7,7,7,7,7,7,7,7`（有界 ≤ 24）。`中文目录` 出现次数 = 1（同一棵树不重复堆叠）。每帧 `overlayEmu.resize` 再喂。
