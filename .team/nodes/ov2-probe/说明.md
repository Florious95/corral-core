# 065 加强探针：三条各自的红证据

- 探针：同目录 `probe-ov2.sh`
- 样本：当前仓 `server/internal/overlay`（PTY 裸字节进 `overlay_frame.text`，`pickSocket` 取第一个可达 socket，scratch 会话名 `am-overlay`，PTY 累积至 128KiB）
- 渲染口径：与真机 App **现在**一样，把 `text` 当普通字符串（`ESC` 剥掉后留下 `[?1049h`）。上一轮探针只验「两帧非空且不同」，乱码也能过。
- 实测（隔离 server `/tmp/ov2-advisor`，`list-sessions` 自检；未碰用户 default）：**三条全红**，exit 1。

## ① 无裸控制序列 — 红

断言：渲染后不得出现 `ESC[` / `[?1049` / `[K` / `(B[m`。

实测最后一帧：

```
FAIL ① 渲染后仍有 ESC[ [?1049 [K (B[m [30m/[43m
```

与用户截图同一类字面量。根因：`overlay.go` 把 `Snapshot()` 的 PTY 原样塞进 `OverlayFrame.Text`，没有过三级终端那条模拟器。

## ② socket 正确且无自我映照 — 红

断言：必须出现目标 socket 上的 `alpha-ov2`；不得出现 `am-overlay` / `tree` / `sleep` / `ov-spin`；订阅带 `socket=sock-a`，不得出现另一个 socket 的 `beta-ov2`。

实测：

```
FAIL ② am-overlay ov-spin tree sleep
```

`alpha-ov2` 此次在帧里（本机 `pickSocket` 碰巧先扫到 sock-a），但观测装置自己也进了树。`tmux.go`：`scratchSession = "am-overlay"`，窗名 `tree`，命令 `sleep`，标题 `ov-spin`。

②a（认订阅里的 socket）用双 socket + `overlay_subscribe.socket` 守着；这次红在 ②b 自我映照。

## ③ 替换而非追加 — 红

断言：连续刷新后行数 ≤ `rows`（24），同一棵树不能重复多份。

实测：

```
FAIL ③ 行数=251 (≤24? false) treeMarks=34 frames=8
last_bytes=28142 last_lines=251
```

`drainPTY` 往 `acc` 里追加（上限 128KiB），`[?1049h` / 清屏没被解释，每次 `refresh-client` 整帧叠上去。

## 对照

064 探针「两帧非空且不同」：这 8 帧字节在涨，旧探针会绿。本探针打的是画面本身。

# 066 附则：改成三段式（换口径，不是为了变绿改探针）

## 为什么换口径

上一版把渲染写死成「与**当时** App 一致：把 `overlay_frame.text` 当普通字符串画（剥掉 ESC，留下 `[?1049h`）」。

那是对的——当时安卓就是这么画的，所以三条全红，打中了真机坏样本。

App 一旦改成 OverlayEmulator（解释备用屏/清屏/SGR，整屏替换），这个口径就**过期**了：

- 继续按「当字符串画」去断言，修好的安卓也会永远红（假红）；
- 或者有人把探针改成在探针里「正确渲染」再断言，那验的就不是安卓了。

065 要验的是**渲染结果本身**。渲染器换成安卓模拟器之后，必须喂**安卓那一份**。

## 为什么不用 JS 模拟器代跑

web MVP（`web/js/overlay.js` 的 `OverlayEmulator`）已经能把同样的流画对：中文树、全展开、8 帧转圈、行数有界。

**探针若改用那份 JS 去渲染夹具，会立刻变绿，而安卓仍然是坏的。** 这是假绿。066 附则写明：被测对象是**安卓的渲染器**，缺一段就会假绿或永远假红。

所以分成三段，缺一不可：

1. **抓夹具**：连**真实**服务端流（隔离 tmux + 本机编的 agentmirrord，`list-sessions` 自检；不碰用户 default socket），把连续 ≥8 帧 `overlay_frame` 的 `text`/`rows`/`cols`/`seq` **原样**写入同目录 `frames.jsonl`。不剥 ESC，不在探针里渲染。
2. **喂安卓**：`app/gradlew testDebugUnitTest --tests '*OverlayEmulatorFixture*'`（由 t.port 写）。单测读这份夹具，逐帧喂进 App 里的 OverlayEmulator，在**最终屏幕文本**上断言 065 三条：①无裸控制序列；②目标会话在、scratch（am-overlay / ov-spin / tree / sleep）不在；③行数 ≤ rows 且同一棵树不重复。
3. **退出码 = 该单测退出码**。探针自己不再对「当字符串画」的结果判红绿。

## 夹具格式

每行一个 JSON，字段来自线上 payload，text 原样（含控制序列）：

```json
{"seq":1,"text":"...","rows":24,"cols":80}
```

## 改完后实测（隔离 `/tmp/ov2-advisor`，未碰用户 default）

```
capture frames=8 last_seq=9 last_bytes=25639 rows=24 cols=80
PASS ① 夹具 8 帧
gradle OverlayEmulatorFixture exit=1
No tests found for given includes: [*OverlayEmulatorFixture*]
```

8 行夹具均含 `text/rows/cols`，text 仍带 ESC（原样，探针不再本地渲染）。② 红在 t.port 尚未产出 `*OverlayEmulatorFixture*`——这是预期：退出码跟单测走，安卓渲染器还没接到夹具上。
