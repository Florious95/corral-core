## 两条红是同一条根因

灯和「查看」都读 `WorkspaceViewModel.viewMenuSource(当前会话 ref)`。
验收席原话「overlay 空（`· 0`）很可能是同一条订阅断了」——查过，**是同一条**。

收藏进会话（验收探针的路径）时：

1. 三栏 `HorizontalPager beyondViewportPageCount=0`，收藏页在屏时 **不组** `WorkspaceScreen`。
2. `enterLevel2` 只挂在二级菜单的 `DisposableEffect` 上，这条路径 **从不订阅**。
3. `enterFavorites` 串行订完就退订，缓存可能有一帧旧 idle，之后不再推。
4. `AgentMirrorApp` 用 `remember(ref, overlayLevel2, overlayFavorites)` 取 overlay，
   **不盯** `favoriteLiveGen`。缓存后到的帧不触发重组。
5. 单测 `VzVerifyLampFollowsLiveOverlayWithoutNavigation` 直接往 `SessionScreen` 灌
   `overlaySessions`，绕过订阅，所以绿。模拟器世界没跟上。

`listConnector` 已经能在会话页占用 `uiConnector` 时把 level2 帧喂给工作区 VM
（083 §10），但会话页自己没发 `level2_subscribe`，扇出槽是空的。

不是两个补丁。只补「会话页在屏必须订当前工作区」。

## 改什么

- `WorkspaceViewModel.enterSessionLive(ref, hint)`：按当前会话解析 cwd
  （收藏 cwd → 缓存 ref → 单例；都空才用 `selectedWorkspaceCwd` hint），
  已订同一 cwd 则不再发（069）。cwd 解析不到只记操作数，不猜。
- `AgentMirrorApp` 会话分支：`DisposableEffect` 调 `enterSessionLive`；
  overlay 的 `remember` 加上 `favoriteLiveGen`。
- `SessionScreen` / `applyLevel2`：灯与帧两边原始数值 + 触发来源 `src=level2-push` /
  `src=session-route` 都记进 `DiagLog`。

未改身份键、未压三态、未把 Unknown 当 Idle。
