# 067 收藏探针：红在哪几条

- 探针：`probe-fav.sh`
- 契约：`requirement-base/entries/067-收藏与三栏布局.md`（四处裁定：窄屏三页滑动、按加入时间倒序、失联置灰不删、身份只用结构字段）
- 夹具：收藏一条 `session_name=favprobe_sess` / `window_index=13` / `window_name=favprobe_win`，标题故意写成不会出现在结构字段里的 `PROBE_TITLE_067_TASKSUMMARY_WILL_CHANGE_xyz`（模拟任务摘要会变的 pane title）

- 当前产品：二级列表无星星、无收藏落盘、设置是布尔覆盖层，没有左收藏 / 中会话 / 右设置的三页 Pager

## ③ 先在「自动移除」写法上验红

契约要求：收藏的会话从 live 列表消失后，**该行仍在且置灰**；默认删掉是不可逆丢失。探针内置「按 live 过滤掉失联行」的自动移除世界，同一条收藏、同一组操作数：

```
auto-remove ① operands blob='[{"session_name": "favprobe_sess", "window_index": "13", "window_name": "favprobe_win", "added_at": 1700000000123}]' title_in_blob=False has_session_name=True has_window_index=True has_window_name=True
PASS auto-remove ① 记录无标题且含结构字段
auto-remove ② operands before_n=1 after_keys=[('favprobe_sess', '13', 'favprobe_win')] want=('favprobe_sess', '13', 'favprobe_win')
PASS auto-remove ② 重建后收藏仍在
auto-remove ③ operands live_before=[('favprobe_sess', '13', 'favprobe_win')] live_after=[] rows_before=[{'key': ('favprobe_sess', '13', 'favprobe_win'), 'online': True, 'gray': False}] rows_after=[] present=False gray=False online=None
FAIL auto-remove ③ 会话消失后未保留置灰行 present=False gray=False online=None
RED-EVIDENCE ③ auto-remove: favorite written, session dropped from live list, row vanished (auto-remove filtered it out) → ③ FAIL as required
```

①② 在自动移除世界上是绿的（结构字段落盘、重建仍在）——红只打在 ③：`live_after=[]` 之后 `rows_after=[]`，行没了，更谈不上置灰。若这条意外绿了，探针自己 exit 2。

## 产品世界（功能未实现，四条全红）

扫描 `app/app/src/main`：`favorite_impl_files=[]`，`persist_fields=[]`，`reconcile_policy='none'`，`pages=[]` `initial=None`。写入收藏后世界没有记录。

### ① 记录不含标题 — 红

```
product ① operands blob='' title_in_blob=False has_session_name=False has_window_index=False has_window_name=False
FAIL product ① 写入收藏后没有持久化记录
```

没有落盘记录，谈不上「键是结构字段」。修完后：写入后的 blob **不得**含标题字符串，且必须含三个结构字段。

### ② 重建仍在 — 红

```
product ② operands before_n=0 after_keys=[] want=('favprobe_sess', '13', 'favprobe_win')
FAIL product ② 重建 App 状态后收藏丢失 keys=[]
```

没有可重建的收藏。修完后：新实例从同一份落盘读出同一把结构键。

### ③ 失联置灰不删 — 红

```
product ③ operands live_before=[('favprobe_sess', '13', 'favprobe_win')] live_after=[] rows_before=[] rows_after=[] present=False gray=False online=None
FAIL product ③ 会话消失后未保留置灰行 present=False gray=False online=None
```

产品世界连行都没有。修完后必须是 `present=True gray=True online=False`。自动移除写法已在 phase 0 验过会红。

### ④ 冷启动中间页 — 红

```
product ④ operands pages=[] page_count=0 initial=None want_pages=['favorites','sessions','settings'] want_initial='sessions'
FAIL product ④ 冷启动不是中间会话页 pages=[] initial=None
```

当前 `MainNavState` 只有 `showSettings` 布尔覆盖，没有三页 Pager。不得把「配对后进工作区」当成「中间页」——那不是三栏里的中间。修完后：`pages=['favorites','sessions','settings']` 且 `initial='sessions'`（`rememberPagerState(initialPage=1)` 或等价枚举）。
