## 开关叫什么、怎么开怎么关

- 名：`debug.agentmirror.keyecho`（`PerfTrace.PROP_KEY_ECHO`）
- 开：`adb shell setprop debug.agentmirror.keyecho 1`，**必须在进程启动前**（与 `debug.agentmirror.perftrace` 同风格，启动读一次）
- 关：不设，或设成非 `1`（cleanup 写 `0`）。缺省 = 关，**即使 PerfTrace 开着也关**（`readKeyEchoProp` 是 `v == "1"`，不是 `v != "0"`）

## 关着时 `onAsciiPrint` 是 null 的证据

没有在设备上 dump 字段（Kotlin 属性进不了 uiautomator）。证据是源码 + 单测，不是「跑过 keyecho」：

1. `TerminalEmulator.onAsciiPrint` 默认 `null`（`:79`）。
2. 唯一赋值在 `SessionViewModel` init，且包在 `isEnabled() && isKeyEchoEnabled()` 里（`:192–193`）。任一为假则赋值不执行，字段保持 null。
3. `print()` 只做 `val hook = onAsciiPrint; if (hook != null && …)`（`:226–227`）——挂钩为 null 时成本就是一次空引用判断。
4. 单测 `keyEcho_独立开关默认关即使PerfTrace开着`：`resetForTest()` 后 `isEnabled()==true` 且 `isKeyEchoEnabled()==false`（`PerfTrace.kt:282–283`，测试 `:45–47`）。JVM 单测当时 BUILD SUCCESSFUL。

开会话测量只 `setprop debug.agentmirror.perftrace 1`、不碰 keyecho ⇒ 挂钩保持 null。

## 显式偏离（不许静默改任务定义）

1. **临时目录**：`keyecho.sh` 的 `NODE` 从注释里的 `.team/nodes/t.instr/tmp/` 改成 `.team/nodes/t.armfix/tmp/`。本格硬约束「临时文件只写 `.team/nodes/t.armfix/tmp/`」，不改判据脚本。unix socket 仍走短路径 `/tmp/e2e-ke.*`（与 e2e 同类例外，worktree 路径超 ~104 字节）。
2. **隔离 daemon 二进制**：本树 `server/bin/agentmirrord` md5 `c8b761b9bcdcfde29ce3aaac9c69293c`（31079970 B）对着本 debug 包时，一级能看到 `1 WORKSPACES · 1 SESSIONS`，点工作区后二级没有 `keyecho_cat`（与 instrperf2 说明同一症状：`snapshots_from_subscribe=0` / 探针 WS `client close`）。换用 instrperf 已验证的 `agentmirrord` md5 `1120f96923d9791a14145e3bdc64dc8e`（31158306 B，来自 `.worktrees/wt-instrperf/.team/nodes/t.instrperf/tmp/`，抄到本格 `tmp/agentmirrord`）后，二级 1s 内出现会话行，量具 n=30 unmatched=0。**被测物仍是本树 debug APK**；换的是隔离 daemon，让 listing/subscribe 对得上。`keyecho.sh` 本来就优先 `$TMP/agentmirrord`。
3. **导航**：配对探针会 `stop()` 掉第一条 WS。脚本在进工作区后 `am force-stop` 再冷启（进程启动前再次 `setprop keyecho 1`），等到 xml 里有 `[1-9] SESSIONS` 才点 cwd；Compose 行 `clickable=false`，点最小 clickable 祖先；二级等到 `text="keyecho_cat"` 再点。假 CLI 仍是 `ln -sfn /bin/cat …/claude` + `exec claude`（白名单 comm；sink 仍是 cat 一对一回吐）。窗口 `rename-window` 成 `keyecho_cat`（二级语义定位）。
