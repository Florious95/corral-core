## 修前验红（A-vw-src）

「查看」浮层读的是 `WorkspaceViewModel.level2` 单例。进二级 / 点星走 `enterLevel2(cwd)`，
把这份单例写成**当时那个工作区**。先收藏 A 再收藏 B 之后，单例钉在 B。
会话页 `AgentMirrorApp` 把 `overlaySessions = overlayLevel2.sessions` 原样塞进浮层，
**当前会话 ref 不参与取数**。

两种同形缺陷用两边的键分开（先量再比）：

| 量 | 先验红读数（`ViewMenuSourceTest` 造 A 后造 B） |
|---|---|
| 当前会话工作区键 `current_ws` | `/Volumes/nvme/Projects/多agent协作` |
| 当前会话 socket `current_socket` | `/tmp/tmux-1000/collab` |
| 单例 `level2`（最后收藏覆盖）`last_published_ws` | `/Volumes/nvme/Projects/远程Agent安卓` |
| 旧路径浮层键（直接读单例） | **B**（与 last_published 相同、与 current 不同） |

判定：**读错了源**，不是「没刷新」。
若是没刷新，单例会仍停在第一次打开的 A，`last_published == current`；
实测 `last_published=B ≠ current=A`，单例已被最后一次收藏写成 B。

## 改了什么

- `WorkspaceViewModel.viewMenuSource(sessionRef)`：按当前会话 ref 解析工作区
  （收藏簿 cwd → 各 cwd 的二级缓存 → 单例里该 ref 自己的 cwd），再取**该工作区缓存**。
  解析不到不回落单例。
- `AgentMirrorApp` 会话分支：`overlaySessions = viewMenuSource(r.ref).sessions`。
- 身份键 / `FavoriteKey` / 073 收藏三条互不串，未动。

## 修后两边的键

同一套 A-then-B 步骤后 `viewMenuSource(REF_A)`：

| 量 | 修后 |
|---|---|
| `current_ws` / `overlay_ws` | A（相同） |
| `current_socket` / `overlay_socket` | A 的 socket（相同） |
| `last_published_ws` | 仍是 B（单例对照，证明不是「没刷新」） |
| 浮层 sessions 的 cwd | 全是 A，不含 B |
