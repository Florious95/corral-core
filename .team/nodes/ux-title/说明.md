# t.title · 会话页顶栏标题仍是旧名（077 §1）

账本 `ledger.ux2.v1` / `t.title` r4。施工在**仓根**（信封最高优先级：判据 cwd 是仓根；忽略派单后半段 worktree）。未 `git worktree add`，未 `git checkout` / `restore`，未 commit，未给 leader 发消息。

## 根因（不是猜）

076 §3a 已经把列表显示名收到 `sessionDisplayName`（`L2Models.kt`）→ `L2Entry.identityLabel` / `FavoriteRow.identityLabel`。

列表**画**的是 `identityLabel`（`远控 leader`），点进去交给 `navState.activeSession.second` 的却是 `navigationName`（`windowName` = `claude_code`）：

- `L2SessionList`：`onOpenSession(entry.ref, entry.navigationName)`
- `FavoriteList`：`onOpenSession(row.ref, row.windowName.ifEmpty { row.sessionName })`

`SessionScreen.TopBar` 只渲染传入的 `name`，没有第二套公式。所以同一会话列表叫「远控 leader」、进去叫 `claude_code` —— 两条取名路径没统一，形状和当年身份键裂开一样。

身份未动：跳转仍走 `ref`（socket + pane id），`navigationName` 仍是结构字段，只是不再拿去当顶栏字。

## 改法

复用已落地函数，不在会话页另写取名：

- `L2SessionList`：`onOpenSession(entry.ref, entry.identityLabel)`
- `FavoriteList`：`onOpenSession(row.ref, row.identityLabel)`

`identityLabel` 就是 `sessionDisplayName`。非 claude_code 窗口 `identityLabel == navigationName`，`L2NavigationIdentityTest` 仍绿。

## 探针（ui-check.sh）

`.team/nodes/ux-title/ui-check.sh`：`adb reverse` → 拉起 App → 自己离开已开会话/从一级进二级 → 记下列表显示名 → 点进去 → `uiassert.py absent claude_code` 且 `has <列表显示名>`。`trap` 关输入法。不起 daemon、不碰用户 tmux。
