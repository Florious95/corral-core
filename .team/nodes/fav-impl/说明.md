# t.fav 收藏实现说明

契约：`requirement-base/entries/067-收藏与三栏布局.md`  
账本：`ledger.favorites.v1` revision 2，本格只做收藏（三栏是 `t.cols`）。

## 做了什么

- 二级行在状态标**左边**加 ☆ / ★，点星收藏 / 再点取消。点星不打开会话。
- 身份键只有 `session_name` + `window_index` + `window_name`（`FavoriteKey` / `FavoriteRecord`）。落盘 JSON 不含 title。
- `SharedPreferencesFavoriteStore`（prefs `favorites` / `records`）持久化；`MainActivity` 注入 VM。
- 排序：`FavoriteBook.rows` 按 `addedAt` 倒序。
- 失联：对账不按 live 过滤掉记录；`isOnline=false`、`gray=true`，UI 标「不在线」。灰行不可点进，星仍可取消。同样结构字段再出现则自动在线，不必重藏。
