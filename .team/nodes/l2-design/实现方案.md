## 0. 一句话

二级菜单 = 服务端按 2s 轮询 tmux 结构字段 + `pane_title` 前缀符号，**变更才推**一行列表（标识 + 状态），App **只收不轮**；零订阅者一次 tmux 都不调；只推变更时必须带低频心跳。

## 2. Wire（跨端钉死，禁止再各写各的）

信封仍是 `{v:1, type, payload}`。

| type（逐字节） | 方向 | payload |
| --- | --- | --- |
| `level2_subscribe` | C→S | `{ "workspace": "<cwd>" }` cwd 非空，必须等于一级 listing 的 `cwd` |
| `level2_unsubscribe` | C→S | `{ "workspace": "<cwd>" }` 幂等 |
| `level2_frame` | S→C | `{ "workspace", "seq", "sessions": [Session] }` 该 workspace 全量替换 |
| `level2_heartbeat` | S→C | `{ "workspace", "seq" }` **无 sessions**；表示连接还活着、本周期无变更 |

`Session`（相对现有 listing Session **增量加字段**，不 bump `v`）：

| 字段 | 含义 | 来源 |
| --- | --- | --- |
| `ref` | 寻址键 | `sessionRef` = socket + `\x1f` + pane_id |
| `name` | 展示名 | `window_name`，空则 `session_name` |
| `cwd` | 工作目录 | `pane_current_path` |
| `title` | 原样标题 | `#{pane_title}`，服务端不 trim / 不剥前缀 |
| `status` | 状态枚举 | **只许** `"working"` / `"idle"` / `"unknown"` |
| `rows` / `cols` | 尺寸 | 结构字段 |

App 徽章文案：`working`→进行中，`idle`→空闲，`unknown`→未知。**禁止** App 再从 title 猜状态。

### 符号表（服务端唯一，认不出 = unknown）

取 `title` 的**第一个 Unicode 标量**（title 空 ⇒ unknown）：

| 符号 | 码点 | status |
| --- | --- | --- |
| `◐` | U+25D0 | `working` |
| `✳` | U+2733 | `idle` |
| 其它 | — | `unknown`，打日志 |

未知日志**必须**同时有：`codepoint=U+XXXX`（大写十六进制）+ `title=` 完整原始标题。只写「符号未知」不算。新 CLI 换符号 = 改这张表，不要在调用点猜 idle。

## 3. 服务端（t.server）

独立于一级 `listingLoop` 的二级循环：

1. `level2Subscribers == 0` ⇒ park，**零次** `Discover` / 零次 tmux。
2. 有订阅 ⇒ 每 **2s** 扫一次（`DiscoverWithDirs` / 现有 Discoverer；**不 attach**）。
3. 每个订阅连接绑定一个 `workspace` cwd。用 `byCWD[cwd]` 取行；cwd 在快照里不存在 ⇒ 推 `sessions:[]`（诚实的空，不是解码失败）。
4. 相对该连接上次已推内容有变更 ⇒ 推 `level2_frame`（seq++）。
5. 无变更 ⇒ **不**重推全量；从上次全量起满 **8s** 推一条 `level2_heartbeat`（seq++）。
6. 0→1 订阅立刻 wake，立刻扫并推第一帧（不要干等 2s，否则 5s 端到端预算被吃掉）。

具名测试（账本 `TestL2*`，必须真跑 PASS）：

| 测试 | 断言「世界变了」 |
| --- | --- |
| `TestL2StructuralFields` | 注入 pane：session/window/socket/cwd/title 已知；发出的 `level2_frame` 里 ref/name/cwd 来自这些字段，**title 逐字节相等**，ref 不含 title |
| `TestL2UnknownGlyphStaysUnknown` | title 以表外符号开头（如 `?foo`）⇒ `status=="unknown"`，**不是** idle |
| `TestL2UnknownGlyphLogsCodepoint` | 同上一次；日志同时含该符号的 `U+` 码点 **和** 完整 title 原文 |
| `TestL2NoPollWithoutSubscriber` | 零订阅期间 Discover/tmux 调用次数不增加 |
| `TestL2PushOnChangeOnly` | 连续两次相同快照只出一帧 `level2_frame`；改 title 后再出一帧且新 status |
| `TestL2Heartbeat` | 快照不变，在 8s 量级内必收到 `type==level2_heartbeat` |

## 4. App（t.app）

- `FrameType.LEVEL2_FRAME = "level2_frame"`（**不要**再叫 `"level2"`）。
- `WorkspaceViewModel.onFrame` 增加 `Level2Frame` / `Level2Heartbeat` 分支。二级 UI 读这个 VM 的 `level2Sessions` / `level2Seq`。
- 进入二级（`selectedWorkspaceCwd != null`）⇒ `subscribeLevel2(cwd)`；离开 ⇒ `unsubscribeLevel2`。`DisposableEffect` 绑屏幕。
- 点行：`onOpenSession(ref, name)`，**title 不参与寻址**。
- 渲染：主文本 = `title` 原样；右侧徽章 = 三态。对 `title` 禁止 `trim/startsWith/contains/replace/substring` 做状态或身份。
- 心跳：刷新「最后一次二级报文」时间；**不**清列表。超时无心跳也无帧 ⇒ 失败可见（横幅），不要假装还是旧状态一切正常。
- 单测：把 `Level2Frame` 喂给 `WorkspaceViewModel.onFrame`（或同等 uiConnector），断言徽章文案与 ref。禁止 `setListener(独立Level2VM)` 当唯一绿。

## 5. 探针与收口

`probe.sh`（本目录）：

1. 短路径隔离 tmux（`/tmp/e2e-l2-design`，`unset TMUX`，`-S` 后 `list-sessions` 自检）。
2. `AGENTMIRROR_E2E_DISCOVERY_SOCKET_DIRS` 只指向该目录；`AGENTMIRROR_STATE_DIR` 隔离；**不听 9900**；不扫、不 attach 用户 tmux。
3. 给隔离 pane 设标题 `◐ <marker>`，auth + `level2_subscribe`。
4. **必须**收到 `type==level2_frame`，且某行 `title` 含 marker、`status==working`。文件存在 / dex 符号 / grep 标识符 **一律不算绿**。
5. 把标题改成 `✳ <marker>`，**5s 内**再收到 `status==idle` 的 `level2_frame`。

回退后功能不存在 ⇒ 探针红。两边按本方案做完 ⇒ 绿。
