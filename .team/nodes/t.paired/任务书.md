# 任务书 · t.paired · 用配对统计重算已有的两轮 A/B（⛔ 不重测，只重算）

## 一、为什么要这一格

第 0 步的性能回测跑了三轮，给了三个互相矛盾的答案。leader 已经拿到决定性证据：

**同一个 A 包（`a706915ef`），同 release、同 `load1 ≤ 12`、同 n=20，只是在两个不同时段各测一次：**

```
绝对漂移：中位 14.6%，最大 25.4%
（real_claude_idle first_draw p95 自己漂了 -25.4%；redraw_tui first_draw p50 漂了 -15.9%）
```

⇒ **量具自身的重复性比要检测的效应（10%）还差。** 现有的两轮红，都在噪声里。

**但根因不是采样方式** —— 已核实 A/B 是**逐样本交替**的
（A 09:32:41 → B 09:33:19 → A 09:34:25 → B 09:36:29 …）。

**根因是统计口径**：现在比的是「A 组的 p50」对「B 组的 p50」——
**交替测出来的配对信息被丢掉了**。慢漂移在组内中位数上不抵消。

## 二、要做什么

**对已有的原始日志重新做配对统计。⛔ 不许重新测量。**

对每个（夹具 × 段），把 A 与 B 的样本**按时间顺序配成对**（第 i 个 A 与紧随其后的第 i 个 B），
然后：

1. 逐对求相对差 `d_i = (B_i − A_i) / A_i`
2. 报 **`median(d_i)`** —— 这是真正的效应估计
3. 报 **bootstrap 95% 置信区间**（对 `d_i` 重采样，≥2000 次）
4. 报 **`n_pairs`**、以及被丢弃的样本数与原因（配不成对的必须单独计数，⛔ 不许静默丢）
5. 同时报**旧口径**（组 p50 之差）放在旁边，让人一眼看出两种口径差多少

## 三、还要回答一个问题（这是本格的真正价值）

**这台量具现在能分辨多大的效应？**

用配对差值的离散度（比如 `d_i` 的 IQR 或 bootstrap CI 宽度）给出一个数：
「在 n_pairs=X 的条件下，本量具能以 95% 置信分辨出的最小效应约为 **Y%**」。

如果 Y > 10%，还要给出：**要把 Y 压到 10% 以下，n_pairs 需要多大**（按 CI 宽度 ∝ 1/√n 估算即可）。

⛔ 不许拍脑袋给数，要从实际的 `d_i` 分布算。
