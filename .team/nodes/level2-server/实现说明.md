## 做了什么

按方案 §5 落地服务端二级菜单实时流。三条不变量逐条写死：

### 不变量①：标题原样显示，零解析

- `protocol/frames.go`：`Session` 新增 `Title string \`json:"title"\`` 字段——pane_title 的**不透明**通道。
- 服务端组装（`api/level2.go` `publishLevel2`）：`title: p.PaneTitle` **逐字节原样**塞进 `Level2Frame.Sessions[].Title`，零 trim/strip/前缀匹配/映射（probe L2-1/L2-4 PASS）。
- 注释明确「Title 是 display-only，永不用于身份」。

### 不变量②：身份只用结构字段

- `sessionRef(p) = Socket + "\x1f" + PaneID`（已有，`api/session.go`）——从结构字段组装，**不含标题字符**。
- `publishLevel2` 组装 `Session.Ref`（= sessionRef）、`Session.Name`（= window_name fallback session_name）。
- 标题字段在整个寻址链路里不参与（probe L2-3/L2-4 PASS）。

### 不变量③：只在二级菜单打开时拉，关掉即停；不 attach

- **协议**（`protocol/frames.go` + `frametype.go` + `validate.go` + `json.go`）新增：
  - `Level2Subscribe{Workspace string}`（C→S，进入二级菜单发）
  - `Level2Unsubscribe{}`（C→S，离开发，幂等）
  - `Level2Frame{Workspace, Seq, Sessions}`（S→C，全量替换快照）
- **服务端 gate**（`api/level2.go`）：
  - `level2Subscribers atomic.Int64` 订阅者计数；`level2WakeCh` 0→1 唤醒。
  - `level2Loop(ctx)`：`countLevel2()==0` 时 **park**（零 tmux 调用）；>0 时按 `level2Interval`（500ms）scan+push。
  - `markLevel2`/`unmarkLevel2` 挂在 `handleLevel2Subscribe`/`handleLevel2Unsubscribe` + teardown（连接关闭自动退订）。
  - `publishLevel2`：一次 `Discover`（list-panes -a，**零 attach**）→ 对每个订阅者按 workspace 组装 `Level2Frame` 推送。
- **ws_conn 接入**：`handleFrame` 加 `Level2Subscribe`/`Level2Unsubscribe` 路由；teardown 退订。
- 不 attach：discovery 用 `list-panes -a`（已有），`level2.go` 无 attach 命令（probe L2-7 PASS）。
