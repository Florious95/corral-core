## 显示名查清（不是猜）

既有代码与测试已经定了主标题字段，本席没有另造一套：

- `L2Entry.identityLabel` = `windowName.ifEmpty { sessionName }.ifEmpty { name }`（`L2Models.kt`）
- `L2NavigationIdentityTest`：`展示名必须来自 window_name，不得来自 title`
- 002：session 名是二级列表展示标签，不参与分组
- 023：别名来自 `#{window_name}`
- 062/067/073：title 不得当身份键

因此：**主标题继续用 `window_name`**（可中文、不截成 ASCII）。同名靠**工作目录副标题**分辨，格式与二级菜单一致：`#index · cwd`。身份只走服务端 `ref`（`Socket + U+001F + PaneID`，`session.go:23`），收藏不再自拼三元组。
