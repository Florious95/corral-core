# 二级徽章冻在「进行中」（t.stale / r7）

## 根因

不是「按身份合并行时漏了 status」——`applyLevel2` 本就是整表替换，订着时 working→idle 会换。

真因：离开二级时 `subscribedWorkspace = null`，退订缝里到达的 `level2_frame` **直接丢掉、不写缓存**。再进去仍画上一次 working。缓存优先被做成了「冻旧状态」。

修复前：`L2StaleStatusReplacedTest` 在「leave → 收到 idle → 再 enter」上红。
（先用「订着时同 ref 换 status」探过：那条路径本来就是绿，不是真因。）

## 修法

- 快照先按 `frame.workspace` 写入缓存，**status 以本帧为准**。
- 当前正在看这个 cwd 才 `publish`。
- 缓存优先保留：再进仍先画缓存，只是缓存已是 idle。

`L2CacheFirstNoBlankFrameTest` / `L2CacheReplacedInPlaceTest` 不得回退。
