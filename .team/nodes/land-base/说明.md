## 做了什么

① 把 `design/compose-handoff/dev/agentmirror/app/ui/` 整包拷进
`app/app/src/main/java/dev/agentmirror/app/ui/`，与现有代码并存。

唯一文件名冲突：仓里已有 `ui/theme/Theme.kt`（`AgentMirrorTheme`）。
设计包同名文件改落为 `ui/theme/AppTheme.kt`（包名仍是 `dev.agentmirror.app.ui.theme`，
`AppTheme` / `Appearance` / `currentTerminalPalette` 都在）。
⛔ 没有覆盖现有 `Theme.kt` / `TermPalette.kt`。

② 三态：`SessionStatus` = `{ Busy, Idle, Unknown }`。
`StatusChip` 与 `RunningDot`（原 `running: Boolean`）都认三态。
灯色：Busy=绿灯亮（保留脉冲）/ Idle=灰灯 / Unknown=红灯。
组件里无字面量色值，全部走 `statusVisuals` / `AppPalette`。

③ 新 token 进 `AppPalette` 浅/深各一份：
`unknownChipBg` / `unknownChipText` / `unknownDot`。
红取自设计调色板已有红（浅 `0xFFC03A62` = TerminalSpec ANSI red；
浅文案 `0xFFB23A63` = `keycapDangerText`；深 `0xFFF0879F` = `keycapDangerText`）。

④ 映射：`sessionStatusFromL2` / `sessionStatusFromWire`。
`L2Status.UNKNOWN` / `"unknown"` / 空串 / 垃圾 → `SessionStatus.Unknown`，
⛔ 不会变成 `Idle`。
