## 一、行为（用户 2026-08-15 裁定，059）

1. **每键直达**：手机键盘每个按键直接进 Agent CLI 输入框（不再 App 本地累积草稿）。
2. **删除键直达**：虚拟键盘删除键同样直通 CLI（不经 App 本地消费）。
3. **发送只提交**：CLI 输入框即草稿，发送键是唯一提交动作（裸 Enter），不再整条注入。
4. **CJK 组合期**（leader 判断，非用户裁定）：组合期归输入法本地、上屏那一刻直通整串；
   退格组合期归输入法、非组合期直通。

## 二、实现（按端）

### 服务端（server/internal/bridge/ + protocol/ + api/ws_handler.go）

- **`bridge.go` 新增 `TypeKeys(ctx, keys...)`**：逐键 `send-keys -l` 注入、**不追加 Enter**——
  直通打字原语。判据 S1。
- **`namedKeys` 加 `"backspace": "BSpace"`**；**`protocol/keys.go` 闭集加 `KeyBackspace`** +
  `IsValid()`——删除键 wire 名 → tmux BSpace。判据 S2。
- **`api/ws_handler.go` `handleInput` 语义改直通**：
  - `AttachmentPath != ""` → `InjectAfterPreview` / `InjectWithAttachment`（提交带图，含 Enter）；
  - `Text != ""` 且无附件 → `TypeKeys`（**打字不回车**，草稿在 CLI）；
  - `Text == ""` 且无附件 → `Inject("")`（裸 Enter 提交）。
  - 旧「text 即整条注入+Enter」被取代。

### App（session/ + conn/Keys.kt + conn/ConnectionManager.kt）

- **`SessionViewModel`**：
  - `sendDraft()` 改为**只提交**：发 `sendInput(ref, "", attachmentPath)`（裸 Enter，不再读本地
    草稿文本整条注入）。判据 S3。
  - 移除本地草稿 `textFieldValue`；`onInputResult` 不再清草稿（无本地草稿），只清附件清单。
  - 新增 `onPassthroughInput(old, new)`：Compose 屏每次 onValueChange 调用，算文本增量
    （`TextDelta.of`），新增直通、删除直通 backspace。**CJK 组合期**：composition 非空时
    不上行（`preCompositionText` 记基线），组合结束上屏整串直通。
  - `sendPassthrough` → `manager.sendKeystroke(ref, char)`；`sendBackspace` →
    `manager.sendBackspace(ref)`。
- **`conn/Keys.kt`**：`InputKey` 闭集加 `BACKSPACE("backspace")`。
- **`conn/ConnectionManager.kt`**：新增 `sendKeystroke(ref, char)`（text=char，不回车）与
  `sendBackspace(ref)`（keys=[backspace]，不回车）。
- **`SessionScreen.kt` `InputBarRow`**：本地 `mirror` 字段（仅 IME 组合期显示载体），
  `onValueChange` → `viewModel.onPassthroughInput(mirror, it)` 再 `mirror = it`——**不累积本地
  草稿**。判据 S4。发送按钮清空 mirror。

## 三、CJK 组合期实现（leader 判断的落点）

`onPassthroughInput` 用 `TextFieldValue.composition` 判定组合期：
- 组合开始（old 无组合 → new 有组合）：记 `preCompositionText = old.text`，不上行；
- 组合中（old/new 都有组合）：不上行（归输入法本地）；
- 组合结束（old 有组合 → new 无组合）：`sendPassthroughDelta(preCompositionText, new.text)`，
  把整串（上屏文本）直通；
- 非组合：逐键增量直通。

退格：组合期归 IME（`composition` 非空时 onValueChange 由 IME 处理，App 不上行）；
非组合期删除经 `sendBackspace` 直通（keys=[backspace] → BSpace）。

**发现更好做法的上报点**：组合期退格「归输入法」由 IME 自身行为保证（组合中退格改组合串，
App 不介入）；若真机实测组合期退格仍被直通（IME 与 Compose 边界差异），需按 leader 判断再
收敛。实现自由度已落在判据结构内，wire 级由 TestPassthroughNoEnter 锁定。
