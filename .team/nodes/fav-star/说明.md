# t.star 点星星不收藏 — 修复说明

日期：2026-08-19  
契约：`requirement-base/entries/067-收藏与三栏布局.md`

## 根因

收藏 UI 已接上 `WorkspaceViewModel.toggleFavorite` → `FavoriteBook.toggle` → `SharedPreferencesFavoriteStore`。

`FavoriteBook.toggle` 在 `session_name` / `window_index` / `window_name` **全空时直接 return**，不落盘。

线上 `Session`（Go `protocol.Session`）只有 `ref` / `name` / `cwd` / `title` / `status`…，**不下发** `session_name` / `window_index` / `window_name`。`name` 已是 `window_name` fallback `session_name`。

因此生产二级行的三元组全是 `""`，点星被静默丢掉。`t.fav` 单测用手工填满的三元组，所以绿。

二次加固：星标从行 `Surface(onClick)` 里拆出独立 hit target，避免点星误进会话。

## 改动（只动收藏身份与点击）

- `Session.toL2Entry()`：空三元组用 `name` 回填 `sessionName`/`windowName`，**永不回填 title**。
- `L2Entry.favoriteIdentity()` / `favoriteKey()`：同样回填，toggle 与星星高亮用同一键。
- `WorkspaceViewModel.toggleFavorite`：写回填后的结构键，并记比较操作数（raw 三元组 / name / title_len）。
- `FavoriteBook.toggle`：空身份 skip 时把三个空字段写进诊断日志。
- `L2SessionList`：行打开与点星拆开。
- 新测 `FavoriteToggleClickTest.starClickWritesStructuralKeyToPersistenceNotTitle`：按生产形态（空三元组 + `name=advisor` + 会变的 title）点 `l2-star-*`，断言 `SharedPreferencesFavoriteStore.load()` 写出结构键、blob 不含 title。
