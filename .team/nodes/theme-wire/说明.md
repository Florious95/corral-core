## 落地

- `TermThemeStore`：`app_term_theme`，键 `terminal-theme-light` / `terminal-theme-dark`，缺键 **Vesper**。
- `TermPalette.of(dark)`：槽 → 族 → `TermSchemeCatalog.colors`；`userBlockBg` 仍按 `dark` 取 APP。
- `token`：`term-theme-dark source=Vesper.itermcolors`（前缀保留）。
- `currentTerminalPalette()`：当前槽拼出的 `TerminalPalette`（16+fg/bg/cursor 主题，userBlock APP）。
- `colorFor`：083 S1–S3 触发不动；`scaleLuma` 取消（近白一律 userBlock）；else 走 OKLab 投影 + 色度分闸 + 前景对比度修补。输出是槽位字面量。

设置页还没有入口时，用 `SharedPreferencesTermThemeStore` / `bindSelectionForTest` 写偏好验证。

## 相对关系 / halt（不准改 userBlock）

默认两槽都是 Vesper（`#101010`）。Vesper 的 ansi0 **等于**纸色，paper≠ansi0 这条在默认族上不成立；`follow-system` 浅半（Alabaster）上成立。

浅纸 vs APP `E6F5F2`（luma 240）翻了的浅半（§3.3 halt，未改 userBlock）：

`catppuccin` / `tokyo-night` / `gruvbox` / `nord` / `kanagawa` / `everforest` / `iceberg` / `zenbones`

色度分闸（ansi 1–6 中 C≥0.06 不足 4）halt 一份：`Melange Dark.itermcolors`。阈值未改。
