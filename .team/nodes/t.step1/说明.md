## 字节怎么切成 `-l` / `-H`，合并策略

`isControlByte`：`b < 0x20 || b == 0x7F`（C0 + DEL）。其余含 UTF-8 中文走 `-l`。

连续同种字节合成 **一次** `runTmux`：

- 可打印 run：`send-keys -t <pane> -l -- <string>`
- 控制 run：`send-keys -t <pane> -H --` + 每字节 `%02x`（`03` / `1b`，无 `0x` 前缀）

R2 载荷 `ab \x03 cd \x1b [A` → **5** 次 send-keys（`callCount==5`），不是每字节一次。先 `requirePane`，不追加 Enter。
