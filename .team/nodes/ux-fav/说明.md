## 3a 显示名（用户已定案，不再猜字段）

| CLI | 取自 | 原因 |
|---|---|---|
| grok 等 | `window_name` | 席位名本身各异（advisor / ux-v1-layout） |
| claude code | `pane_title` 剥 062 前导符号 | `window_name` 恒为 `claude_code` |

剥符复用 `server/internal/api/l2detect_claudecode.go` 的同一套 `◐◓◑◒` / `✳`（`claudeCodeStatusRune`），Kotlin 侧 `CLAUDE_CODE_STATUS_PREFIXES` 与之逐字对齐，禁止另写符号表。

显示名只用于 `identityLabel`。`navigationName` / 收藏键 / 落盘仍走结构字段 + socket（062/067/073 不动）。中文不截断（`远控 leader` 原样）。

模拟器实测三条 claude code 显示名：

- `leader`（讨论team-agent）
- `远控 leader`（远程Agent安卓）
- `team-leader-2`（多agent协作）

互不相同，不是 `claude_code (1)/(2)/(3)`。grok 仍显示 `advisor` / `ux-v1-layout`，没有改用会变的 pane_title。

## 3b 状态标

收藏在线行的 `status` 从 live `L2Entry.status` 拷贝（即线上 `Session.status` → `L2Status.fromWire`），UI 走同一个 `L2StatusBadge`。
禁止从 title 再算一遍：测里 title 是 idle 字形、wire 是 `working`，徽章必须是「进行中」。

失联行仍标「不在线」，不另造一套。

## 3c 布局

收藏行与会话列表同构：星在行首（复用 `L2FavoriteStar`）→ 标题 → 目录副标题 → 右侧状态标。
