# t.fix · bad_frame 空白窗

契约：`requirement-base/entries/070-悬浮窗回炉与跨语言线上帧判据.md`  
探针 `probe-wire.sh` 未改。

## 根因

`sessionSocketFromRef` 只切 U+001F。listing 金样 `ref=s1` 无分隔符，整段回落成 socket=`s1`。结构 ref 若带着字面 `\u001f`（六字符）也切不开。发出去的 overlay_subscribe 不是可订阅的 tmux socket。

070 §2「空字符串 ⇒ ErrInvalidField ⇒ bad_frame」是服务端对空字段的映射；探针坐实的线上值是「有字段但不是路径」。两边叠在一起就是空白窗 + `malformed frame`。

## 修了什么

1. App：`sessionSocketFromRef` 切 U+001F 或字面 `\u001f`，结果必须含 `/`。空则 **不发** overlay_subscribe，`transientError` 写清 ref。
2. 仪表：`[overlay]` 记 ref / sep / socket / sent、帧 seq+bytes、error_frame 的 code+reason。
3. 服务端：`ErrInvalidField` → 错误码 `invalid_field`，reason 带字段名（含 socket）。JSON 烂了仍是 `bad_frame`。
