## 哪些结论是从代码原文读出来的

1. **当前输入模型是整行 + 闭集命名键，不是逐键。** 证据：`frames.go:153-156`、`Frames.kt:328-333`。
2. **每个 input 必有 input_ack。** 证据：`frames.go:156-157, 247-250`、`Frames.kt:369-371`。
3. **闭集在客户端是八个名字键。** 证据：`Keys.kt:41-64`。Go 侧闭集字面量不在点名的 `tmux.go` 里（见下「判不出」）。
4. **未知名字键在调 tmux 前失败。** 证据：`tmux.go:39-42`。
5. **已经存在一条「滚轮 → 原始鼠标字节（SGR 或 X10）」路径**，成功无 ack。证据：`frames.go:305-319`。这与交接文档「鼠标完全没有」的字面说法不一致（见下），但不否定「点击进不了 Agent TUI」这一现状——滚轮路径不是点击归属。
6. **本仓许可证文首是 Apache 2.0。** 证据：`LICENSE` 第 2–3 行。

- 交接 `.team/artifacts/HANDOFF-leader-20260823.md` §4.A：「鼠标完全没有（grep 到的 `SGR` 全是 Select Graphic Rendition 颜色样式，不是鼠标 SGR-1006）。」
