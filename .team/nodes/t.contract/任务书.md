# 任务书 · t.contract · 输入透传「输入模型契约」落纸

## 一、背景（读这一段就够，⛔ 不必回溯对话）

本工程是「手机远程操控主机 tmux 里的 Agent CLI」。**现状**：客户端只能把**整行文本**或
**一个闭集里的名字键**送到服务端（见下方必读坐标），所以用户在手机上**点不动**里面那个
Agent TUI 的界面、也发不出任意控制字节。

**下阶段目标**：让**所有键盘操作与鼠标点击对被投影的 Agent 界面完全生效**。

**用户已裁定的两件事（⛔ 是前提，不是待议项）**：

1. **鼠标事件归属 = 里面的 Agent**，⛔ 不是 tmux。
   用户原话：「鼠标事件是要给 Agent 的。就比如说你调用了一个工具，你点这个是可以看到它具体
   调用什么；你改了代码，我能看到它完整改的代码」——即点击要落到 Agent TUI 的可折叠区域上。
   **直接后果**：外层 tmux 的 `mouse on` 必须关掉（或等效地不让 tmux 截获），否则点击被 tmux
   自己吃掉去切窗格，**永远到不了里面的 Agent**。这一条必须写进契约。
2. **性能基线不许降低**：每一步改动都要有性能回测（这一格本身不碰产品码，故不占回测轮次）。

## 二、这一格要交付什么（路径级，⛔ 少一项都算没交付）

### 产物 1：`docs/输入透传契约.md`（仓根，新建）

必须**逐节**写清下面 7 件事。每一节都要写「**决定是什么**」+「**为什么**（依据）」+
「**违反了会看到什么现象**」三段——第三段是给后继排障用的，⛔ 不许省。

1. **鼠标事件归属**：给里面的 Agent（用户裁定，原话见上）。
   必须写明「外层 tmux 必须不截获鼠标」这一推论，以及**怎么验证 tmux 没在截获**。
2. **鼠标坐标编码：只用 SGR 1006**（`CSI < Cb ; Cx ; Cy M` 按下 / `m` 抬起，纯 ASCII）。
   ⛔ 不用 X10 / 1005 / 1015。依据：X10 编码把坐标塞进单字节 `32+coord`，**超过 223 列/行就废**，
   且在 UTF-8 模式下实测被卡在 127（见参考资料 xterm.js #1962）。
3. **跟踪模式：安卓上用 1002（cell-motion），⛔ 不开 1003（any-motion）**。
   依据：1003 会把**每一次鼠标移动**都变成上报，实测压垮 PTY 转发（见参考资料 Termux/PRoot）。
   1002 已足够：手指滑动映射成滚轮事件即可。
4. **重连时必须按原顺序重放模式设置**：记录 app 发出的**每一个模式码、它的开/关状态、以及到达顺序**，
   重连后按**原顺序**重放。依据：编码方式（1006/1015/1005）与协议（1000/1002/1003）在实现里
   **互为互斥组，谁后设谁生效**；顺序错了会**静默**退回有字节上限的旧编码——不报错，只是坐标错。
5. **ack 策略**：现有协议规定每个 `input` 必回一个 `input_ack`。逐键透传之后，这会变成
   **每敲一个键一个网络往返**。必须在这一节里**与预测性本地回显一起设计**——
   ⛔ 不许把「逐键 ack」和「本地回显」分成两次决定。
   至少要回答：ack 是否可以批量/可否降级为周期性、本地回显在 ack 未回时展示什么、
   ack 回来与本地预测**不一致**时怎么收敛。
6. **`tmux send-keys` 的用法**：可打印文本走 `-l`（字面量），**只有控制字节才走 `-H`**，
   且**批量成一次调用**。依据：`-H` 每个字节会被展开成 5 个字节（`0x2f 0x62 ...`），
   iTerm2 因此被报过输入速度 bug（见参考资料）。
7. **许可证边界**：本工程是 **Apache-2.0**。Termux 的 `terminal-emulator` 与 mosh 都是 **GPLv3**，
   ⛔ **不能 vendor / 不能复制代码**，只能**当参照实现阅读**。xterm.js 是 **MIT**，可参考甚至移植
   （移植需保留其版权声明）。这一节必须给出**结论性的一句话**：哪些仓可以抄、哪些只能读。

另外必须包含一节 **「改完仍不生效的已知坑」**，至少两条：
- **内层 app 自己没开鼠标上报 = 白改**。判据现象：**拖拽变成了选择复制**，说明它没进 tracking 模式。
  验证手段：`script` 或 `cat -v` 看它有没有吐出 `\x1b[?1002h` `\x1b[?1006h`。
- **tmux 层截获**（见第 1 节）。
