# 任务书 · t.idlecpu · 服务端空闲烧 CPU：先复现，再定根因

## 一、用户实撞（这是最高优先级，⛔ 不是理论问题）

用户 2026-08-23 报：**「APP 打开会话不是很迅速，没有之前迅速。局域网的情况下白屏时间那么长。」**

⚠️ 真机体验是本工程的**最终判据**（金标准＝「秒开无空白」）。量具说什么都不能推翻它。

leader 已排除的：

- **服务端源码没变**：`server/` 从 `baseline-20260822-release` 到 main **0 个提交、diff 为空**。
- **生产二进制没换**：跑的是 `agentmirrord-night-4120c0884`，**连续运行 33+ 小时**，
  覆盖了用户 8-22 那次「秒开无空白」的金标准 ⇒ 同一个二进制既给过好体验、现在给差体验。
- **用户手机 APP 也没变过**（用户原话）。
- 用户明确否认了「VPN 全局转发」这条。

**leader 实测到的异常**：生产 daemon 在只有 1–3 个订阅者、没人操作的情况下，
CPU 连续采样为 `0.0 / 17.0 / 33.6 / 21.6 / 34.3 / 33.7 / 27.4 / 18.2`（%），内存稳定 21MB。

⇒ **违反本工程「工程常识红线」第 1 条：静默经济——空闲 CPU 必须趋近 0。**

## 二、这一格要做什么

### 第 1 步：复现（⛔ 复现不出就不许动代码）

**⛔ 绝对不许碰生产 daemon（`:9900`，pid 16330）。** 自己起隔离 daemon。

用 `4120c0884` 这个 commit 的服务端源码构建一个隔离 daemon（高端口，⛔ 不是 9900），
在**三种负载态**下各采 CPU ≥60 秒（采样间隔 1s，落原始序列）：

| 态 | 说明 |
|---|---|
| **N0** | 零连接、零会话 |
| **N1-idle** | 1 个订阅者，订阅的 pane 里跑一个**完全静默**的东西（如 `cat`，⛔ 不是 shell） |
| **N1-busy** | 1 个订阅者，pane 里持续有输出（作对照，说明"有活时烧 CPU"是正常的） |

**判据要的就是这三组数**。如果 **N0 或 N1-idle 的 CPU 明显不趋近 0**，复现成立。

⚠️ **如果复现不出来**（隔离 daemon 三态都趋近 0）：那是**合法且重要的结果**——
说明烧 CPU 来自生产环境特有的东西（会话数量、某个特定 pane、tmux 规模、
或 33 小时累积的状态）。**照实报 `not_reproduced`**，并在说明里写清你试了哪三态、各是多少。
⛔ 不许因为复现不出就去猜一个根因。

### 第 2 步：定根因（只有复现成立才做）

Go 的 daemon 优先用 **pprof**（若二进制没开 pprof，就在你的隔离构建里加上，
⛔ 只加在你自己的隔离构建里，不许改仓里的产品码）。
拿到 CPU profile 的 top 帧，指出**是哪个循环/定时器在空转**，附 profile 原文摘录。

常见嫌疑（供参考，⛔ 不要预设答案，以 profile 为准）：
轮询 tmux 的定时器间隔过密、每 tick 全量 `list-panes`/`capture-pane`、
snapshot 无变化仍重算、sendq 健康日志过密（生产日志里 `ws: sendq health` 出现频率很高）。

## 四、硬约束

- ⛔ **绝对不碰生产 daemon `:9900` / pid 16330**，⛔ 不碰用户真实 tmux。
  隔离 tmux 照 `e2e/layer2.sh` 的做法：`mkdir -p /tmp/e2e-idlecpu`（短路径且预建）→
  `unset TMUX` → `tmux -S <sock> new-session -d` → **`tmux -S <sock> list-sessions` 自检**
  （⛔ 自检不过立刻停手：tmux 建 socket 失败会**静默回退到用户真实 socket**）。
- ⛔ 不许改仓里的产品码。这一格只**复现与定位**，修复另立格。
- ⛔ 不 commit / 不 push；⛔ 临时文件只写 `.team/nodes/t.idlecpu/tmp/`。
- ⛔ 不读凭据；⛔ 无过滤 `ps aux`（取进程只用 `ps -o pid,ppid,etime,stat,comm`）；
  ⛔ 不 `tail` 生产日志 `.team/logs/agentmirrord-prod.log`（它明文打配对 token）。
- ⛔ 收工时把你起的隔离 daemon 与 tmux **全部停掉**，说明里写清你起了什么、停了什么
  （零孤儿零残留端口是本工程的红线之一）。
