# t.glyph · 框线/块缝几何化 + onDraw 日志去重

账本 `ledger.vz.v1` / `t.glyph` r10。施工在 worktree `.worktrees/wt20.glyph`。未 git checkout/restore，未 commit，未给 leader 发消息。

## 根因

框线 U+2500–257F 与块元素 U+2580–259F 走 `SYSTEM_FALLBACK` → `drawCentered`：
`measureText` 自然宽 < 格宽，再居中，两侧留 `(cellPx-advance)/2`。
绘制依赖「字形自然宽度 + 亚像素取整」，**非整数密度必崩**；居中是放大器。
logo「黑底」= 块与块之间的缝里露出了主题背景。两条同一根因，一处修。

## 修法

- 这两类码点改用 `BoxBlockGeometry` 按**整数格边界**画矩形，不用字形、不 textScaleX。
- `█` 整格 / `▀▄▌▐` 半格 / `░▒▓` 透明度；框线映射成边+粗细；`╱╲╳` 用 1px 阶梯。
- `handles` 覆盖整段 U+2500–259F。
- `GlyphFallbackPolicy` 对这类码点直接 `SYSTEM_FALLBACK`，避免 MONO hasGlyph 拐进 batch `drawText`。
- `geomPaint.isAntiAlias = false`。
