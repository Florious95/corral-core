## 三项返修机械契约

1. Canonical：真实入口固定为候选 WT 的 `tools/perfbase/baseline_bundle.py retrieve`。同一真实 manifest fixture 仅改变 `build.independent_builds[0].apk_relpath`/对应 `bundle_id`：stale manifest 必须精确因 `manifest bundle_id mismatch` 被拒绝，final manifest 必须成功取回。判据禁止重写 synthetic hash 恒等式。
2. SDK 与 IMPL：`app/local.properties` 只核存在/可读/非空、`sdk.dir` 可达、`apksigner`/`aapt` 可执行；不得输出文件内容、SDK 路径或工具明文，缺失 exit 2。`IMPL.md` 末行非 `implementation: pass`（含 unjudgeable）为 1。
3. Controlled bypass：固定 fixture 是 Git 跟踪路径 `.team/ledgers/acceptance/fixtures/baseline-bundle-successor3/control-contract.json`，缺失/摘要漂移 exit 2。canonical 绿色控制 rc0，仅改 `implementation.bundle_py.sha256` 后由真实 retrieve 精确以底层 rc2 报 `manifest bundle_id mismatch`，hardened 齿将这一精确伪造形状归类为 1，不吞掉其它 rc2；measure 绿色控制 rc0，仅改声明的 `runner_sha256` 后由 hardened 门 rc1、底层精确报 `runner provenance mismatch`。两组 root 均合法、raw 非空；`repository root mismatch` 或 `empty raw log` 不得满足 bypass 齿。
4. test/probe 的便宜 grep gate仅证明 RED.md/PROBE.md 交付形状，不得冒充独立事实覆盖；实现完成后的 verify/final 必须 fresh 执行 canonical/bypass 真实入口门并可否决。

## 不得弱化的产品终局

- 缺冻结 A 诚实走 `blocked_missing_baseline`，只允许 `recover_exact_artifact` 或 `rebaseline_with_equivalence_proof`；
- A2 等价与不可变 Baseline Bundle 覆盖源码、归一化运行内容、制品/签名、构建/等价报告、双归档取回和安装；

- 不改 App/server，不公开分发 debug APK，不读凭据，不修改/清理/重派旧 ledger/attempt。
