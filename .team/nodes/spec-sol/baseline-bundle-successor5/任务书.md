## SDK 选择、白名单 fallback 与生成契约

所有可能运行 Gradle/Android SDK 的 test、probe、impl、verify、measure、final 在任何 Gradle/SDK 操作前必须先运行 `baseline-bundle-successor5-sdk.sh`：

1. 若 `ANDROID_SDK_ROOT` 指向存在、可读可进入的目录，优先选它；否则尝试同条件的 `ANDROID_HOME`。只核布尔，不打印、记录或回传值。
2. 两者均无有效目录时，从 Git common dir 推导主仓根，只把主仓根 `app/local.properties` 交给固定 helper。禁止用调用方参数、替换 root 或任意文件覆盖该来源。
3. 源文件 UTF-8 逐行白名单：只允许空行、去除前导空白后以 `#`/`!` 开头的注释，以及恰好一行、从行首开始的 `sdk.dir=<非空值>`。出现任何其它键/语法、重复 sdk.dir、缺 sdk.dir、无效目录或不可读文件均 exit2；不得 `source`、不得打印内容或值。
4. 不得原样复制源文件。helper 只在目标 WT 原子生成唯一一行 `sdk.dir=<已验证目录>`，权限 `0600`；目标必须未被 Git 跟踪，误入 Git 为 exit1。输出/日志不得含 SDK 路径。
5. 环境变量设置但无效时仍可回退到安全源；有效环境变量必须优先，哪怕源文件含额外键。任何输入路线成功时 gate stdout/stderr 都为空。
6. 不读取 provider profile、`tailnet-test.env`、Shadowrocket plist、`tailscale_keys.bin`、生产 daemon 明文日志或其它凭据。目标 `app/local.properties` 不提交。

`baseline-bundle-successor5-sdk-regression.sh` 永久锁定：安全 fallback=0/无输出/仅一行/0600/未跟踪；额外键=2；重复键=2；无效目录=2；被 Git 跟踪=1；有效环境优先=0；无效环境回退=0。量具/真实安全源不可用为2。
