## 3. AVD 创建精确契约

### 3.1 目标身份与前置

固定 package 为 `system-images;android-35;google_apis;arm64-v8a`，固定 device profile 为 `pixel_6`。SDK root 必须先由 successor9 selector 得到唯一有效 root；helper 只接受该 root 下精确 `cmdline-tools/latest/bin/avdmanager`，并重做 executable/canonical-within-root 与 exact readable regular/non-symlink `package.xml` 检查。不得换 image/API/ABI/device，也不得接受调用方替换 production root。

`ANDROID_AVD_HOME` 必须位于本任务 node-local run root，是本 case 新建的 regular directory、mode 0700、无已有内容。production AVD name 必须由 helper 生成，匹配 `successor10_[a-z0-9_]+` 且在该 home 中不存在同名 `.avd`/`.ini`；fixture 固定名只在显式 test mode=1 的本格隔离回归中允许。已有 name、非空 home、symlink/non-directory 或 mode 不等于 0700 都必须在调用外部工具前 fail closed。

创建前以相同净化环境和有限时命令运行精确 `avdmanager list device -c`，输出必须包含 exact `pixel_6`。创建 argv 固定为：

`avdmanager create avd --force --name <generated> --package system-images;android-35;google_apis;arm64-v8a --device pixel_6`

stdin 必须是 `/dev/null`，禁止 `printf no | ...`、license 自动同意或任何交互输入。每次外部调用建立本任务独占 process group；到 deadline 后 TERM，3 秒内未退出才只对该 owned group KILL，再有限 wait。未知停机事实不得继续 launch。

- `hw.device.name=pixel_6`
