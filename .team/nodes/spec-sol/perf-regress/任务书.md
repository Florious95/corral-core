- B：revision=`565542972`，md5=`3ebc9c55703c780c842a2f410b85034e`；

   - `PerfRegressionBigScrollbackControlTest`

   - `.team/nodes/perf-regress/raw/A/` 与 `raw/B/`，各至少 30 份原始 PerfTrace 日志。

严格先红：先只加三类聚焦测试与 `test-perf-regress-attribution.sh`。测试必须执行真实产品入口，不得复制一份算法自测；当前代码至少有一条关于所选因果操作数的断言应红，big_scrollback 对照应绿。把红原文落 `ATTRIBUTION.md` 后才能改产品。若测试全绿、只能复述 r13 的墙钟比例而无法命中一个结构性操作数，根因尚未必现，停止修复并报不可判。

### 归因必须回答的操作数

`tap_to_route_enter` 至少拆出：tap 事件时刻、`activeSession` 写入前后、route 组合入口、主线程队列等待、同次打开的状态写次数/组合次数；日志须带 open_id/ref、线程与两边时间。禁止用人为 sleep 制造红。

`first_frame_to_first_draw` 至少拆出：first frame 到达、snapshot replay 入口/出口、invalidate/requestLayout 请求次数与时刻、`onDraw` 入口/出口、首个 glyph>0 时刻；必须分清 replay CPU、主线程排队、View `onDraw` CPU 与 onDraw 返回后的 HWUI/GPU 未观测区。无法观测的区间明确写“未判”，不得用 `TermDrawMeter` 的旧批次结论替代本批因果证据。

只能选择一个已经满足以下合取的根因后动产品：

1. 修前聚焦测试在真实入口稳定红；
2. 该操作数在失败夹具出现，big_scrollback 对照不出现或有明确规模差；
3. 去掉/合并/移出关键路径后测试绿且行为输出等价；
4. 独立判者能临时恢复该操作或撤掉防线，使同一测试红，而 big_scrollback 对照仍按预期绿。

破坏齿由实现完成后的独立判者选址；任务书只冻结齿的性质，不指定具体行号。

## 三、机械验收与性能复测

修后先跑：

```sh
sh tools/perfbase/test-perf-regress-attribution.sh
./gradlew :app:testDebugUnitTest --rerun-tasks
python3 tools/archwiki/build_wiki.py --check --strict-t3
```

随后构建新 release 候选 B'。B' 的 source revision 必须不同于 `565542972`，md5 必须同时不同于 A 的 `0907...` 与旧 B 的 `3ebc...`。同一 revision+md5 只允许一批有效测量；若仍红，不得重跑同包抽绿，只有新的因果代码变化和新 md5 才能再测。

新测量沿用冻结正本，不得发明新口径：先 `sh tools/perfbase/envcheck.sh --gate`，再用现有 `run-input-ab.sh`；同一时段 A/B/A/B、三个固定夹具、四段、每包每格 n>=10、极端值不删，nearest-rank p50/p95 的每一格 B/A≤1.10。A 仍是稳定 tag+参考 md5；不得改 `MAX_LOAD=12`、死 socket/daemon CPU 阈值、样本数、夹具、四段或 1.10。

`.team/ledgers/acceptance/perf-regress.sh` 会：

- 真跑 POSIX 聚焦入口并核三类真实入口测试与 `--rerun-tasks`；
- 要求归因/实现/测量文书与 raw 日志非空；
- 独立解析 `perf-ab-fixed.json`，用与现行门相同的 nearest-rank 重算全部三夹具×四段 p50/p95；
- 拒绝复用旧 B md5/revision、相同 A/B、无效 order/env 或缺样本；
- 任一比例 >1.10 均 exit 1，不采信 JSON 自报 pass。

产品行为也必须不倒退：会话仍能秒开并显示非空首绘，三个夹具事件单调且同 open_id，连接/订阅语义不变，PerfTrace 关时仍走零额外分配/零固定频率后台工作。实验室全绿只可写“新候选通过可执行门”；最终“性能优化成功”仍须用户在蜂窝+广州中转真机确认秒开无空白。

## 四、四态与合法出口

- **通过 / exit 0**：修前因果红、修后绿和独立破坏齿成立；三类真实入口聚焦测试与全量测试无缓存绿；新 revision/md5 的唯一 fresh 批三夹具四段全部≤1.10；raw、身份、order、env 与文书齐全。
- **失败 / exit 1**：量具有效但缺聚焦测试/产物，测试语法或断言红，所选机制不是因果，行为对照倒退，复用了旧 B，或新批任一格仍>1.10。用户真机“感觉良好”不把本态改成通过。
- **不可判 / exit 2**：无法重建 B/新候选身份，测试/Gradle/Python/夹具不可用，环境闸非 0，A/B 身份相同或缺失，order/事件/样本/raw 不足，或只能看到 onDraw 外等待却不能进一步归因。不可判不得染成失败或通过。
- **不适用**：仅由账本在本格从未派发时表达；已派发但没跑起来是不可判。

若安全修复必须扩大到 server/core、改变协议或改变性能口径，停止扩大范围，在 `ATTRIBUTION.md` 写清证据与需 leader 裁定的边界。required artifacts 齐后正常出口只调用标准 `report_result` 一次；不 merge、push、打 tag，不主动发消息给 leader。
