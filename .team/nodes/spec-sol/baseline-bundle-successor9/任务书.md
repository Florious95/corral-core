## 3. selector 精确契约

### 3.1 候选来源与去重

只收集四种 source label，不记录或输出值：非空 `ANDROID_SDK_ROOT`、非空 `ANDROID_HOME`、Git common root 的 `app/local.properties` 唯一白名单 `sdk.dir`、PATH 中可执行 `sdkmanager` 的 canonical executable-derived root。source local 只允许空行、注释和唯一绝对 `sdk.dir`；未知键、重复键、控制字符、首尾空白或反斜杠转义使该 source candidate 无效，但不得盖过其它有效 root。

每个现存目录先 canonicalize，再按 `(st_dev, st_ino)` 去重；环境、source 与 sdkmanager 指向同一实体只能计一个 root。不得按来源优先级“先到先得”。

### 3.2 每个 root 的完整验证

对每个去重 root 独立重做，且所有外部 stdout/stderr 均捕获、不得透出路径或值：

1. root 为可读可遍历目录；
2. exact `system-images/android-35/google_apis/arm64-v8a/package.xml` 是可读 regular、非 symlink file；
3. 同 root 内 `platform-tools/adb`、`emulator/emulator`、与 sdkmanager 同目录的 `avdmanager` 均可执行，canonical path 不逃出 root；
4. 同 root 的 sdkmanager 以精确 argv `--sdk_root=<candidate> --list_installed` 在 30 秒内 rc0，输出 pipe 左操作数精确包含固定 package id。

最终 valid root 数必须精确为 1。0 或大于 1 都是 apparatus 事实不足，exit 2；invalid source-local + 唯一 valid sdkmanager-derived 必须 exit 0。不得把阈值调宽、把 `source.properties` 代替 exact package XML，或在多 root 时猜一个。

### 3.3 目标 WT 写入

目标坐标只能是当前 Git worktree 的 `app/local.properties`。写前必须机械确认它已存在、未进入 Git index、是 regular/non-symlink，且内容只能含空行、注释与至多一个语法严格的绝对 `sdk.dir`。允许把当前两行合法形状收敛为一行；目标缺失是 apparatus 前置不足，exit 2，不得由本格猜测创建。

写入用同目录 0600 临时文件、flush+fsync、`os.replace` 原子替换、目录 fsync；结果必须精确一行 `sdk.dir=<唯一 root>`、mode 0600、仍未 tracked。不得原样复制 source 文件，不得保留注释/其它键，不得提交，不得在 stdout/stderr/日志写出 sdk.dir 或路径值。

映射明确如下：

- 已 tracked、symlink/non-regular、未知/重复 key、target sdk.dir 转义或畸形，是安全/身份契约被反证，exit 1，且不得改写原文件；
- 目标缺失、Git/stat/read/write/timeout 工具不可用，或 valid root 数为 0/多于 1，是环境不可判，exit 2；
- 无效候选本身不提前退出；若另有唯一完整 root，继续并 exit 0。
