# 019 键盘弹出：视口上推，不触发重绘

## 命中三：taskbook 已把该族裁定写成完整规则

`fix-terminal-resize-cluster` 的 goal 原文：

> 规则（用户裁定）：**仅首次进入 CLI 时 resize 一次，此后键盘/输入框不触发 resize**；
> 捏合缩放松手后发一次 resize（过程中只做本地视觉缩放）；退出时恢复原始尺寸。

**这条规则是本任务的完整规格。** 三句分别对应：
① 首次进入 resize 一次 → 本任务需保留
② 键盘/输入框不触发 resize → **本任务要兑现的就是它**
③ 退出恢复原始尺寸 → D-21，另行排期

## ⚠️ 与 D-20 的边界（上届在此混淆过）

同一条裁定拆成两半，**已完成的只有前一半**：

| | 状态 |
|---|---|
| ① 键盘弹出**不遮挡**内容（视口上推） | ✅ 已修（`ui-redesign` commit「IME 空洞根治」，在 git HEAD 内） |
| ② 键盘/输入框变化**不触发 resize**（rows/cols 不变） | ❌ **从未实现，本任务即它** |

交接文档把 D-20 记作「已修已验证」，只覆盖①。
**「不遮挡」≠「不 resize」，不可互相代替。**
