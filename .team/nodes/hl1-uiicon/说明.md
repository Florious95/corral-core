## 改点=

- `ProviderIcon` 整族重绘为圆润小机器人/小怪物 Canvas glyph（自绘，不拷参考图版权素材）；去掉不透明井底。
- 新增 `busy: Boolean`：`true` 实底彩色，`false` 灰色描边。`stateDescription` 为「运行」/「空闲」。
- 会话列表 / 收藏列表 / 切换 sheet 按 `item.status == Busy` 传入 busy。
- 单测 `glyphResources_pairwiseDistinct_andBusyIdleDiffer`：`glyphGeom` 六家两两 `assertNotEquals`（复制几何会红）；同一 id 运行/空闲 `ProviderIconResource` 不相等（filled/color）；12 份资源 `toSet().size==12`。well 仍不得是实心白底。
- 绘制坐标系 `scale` 必须 `pivot = Offset.Zero`（默认中心 pivot 会把 20 单位 glyph 甩出 32dp 画布）。
- 补证屏 `ProviderIconFamilyBoard`：仅 `am start --ez provider_icon_board true` 挂上，不进主导航。
