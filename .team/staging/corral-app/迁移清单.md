## 还留在 core 里的 Android 残留（明写，未全部剥离）

1. **本 git 仓 `app/app` 仍是完整 Android 壳**（t.core 只做仓内切分，没删壳）。本格只造暂存引用工程，**没有**从 本仓删掉 `MainActivity` / Compose / `TermSurfaceView`。
2. **`corral-core` 三核源码**（`core-protocol` / `core-terminal` / `core-conn`）：**零** `import android.` / `import androidx.`，无 `com.android` 插件。`:terminal` 门面同样纯 JVM。
3. **Android 全在壳**：`corral-app/app` 含 AGP、Compose、CameraX、OkHttp、`tsnetbind.aar`、前台服务、PerfTrace（`android.util.Log` / `Handler`）。这是壳该留的，不是核残留。
4. **核依赖由壳注入**：`ConnPerf` / `ConnDiag` 在核里是回调；实现仍在壳的 `PerfTrace` / `DiagLog`。
5. **快照与 live 树双份**：`corral-core` 是 t.core2 的拷贝，不是 git submodule。本 worktree 的 `app/` 仍无核模块。
