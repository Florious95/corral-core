# AgentMirror UI 预览

独立、可点击的前端预览：给产品负责人在浏览器里看「终端深夜」外观和交互。
**没有后端**，不改 `app/` Kotlin。

## 怎么开

```bash
cd ui-preview
npm install
npm run dev
```

浏览器打开终端里打印的地址（默认 `http://localhost:5173`）。

桌面会看到一部约 **390×844** 的手机框；窄屏会铺满窗口。

静态构建：

```bash
npm run build
npm run preview
```

路径截断自检：`npm test`。

产物在 `dist/`。

## 点什么

默认落在 **收藏**，深色主题。

1. **收藏 ↔ 会话 ↔ 设置** — 底栏三个页。选中态是顶边指示轨，不是圆胶囊。
2. **会话** — 工作区列表。点「远程Agent安卓」进入该工作区的会话列表。
3. **打开会话** — 点「远控 leader」或「claude_code」进终端页。
4. **查看** — 终端顶栏右侧。深色底栏滑出切换器（与外壳同色阶，不是白卡压黑屏）。点行切换会话，点遮罩关闭。星标可点。
5. **输入 + 发送** — 底部输入框打字，点 `↑` 或回车，假终端追加一行回显。`Esc` / `Tab` / 方向键 / `Ctrl-C` 也会落一行。
6. **星标** — 收藏页、会话列表、切换器里都能开关；取消收藏后该行离开收藏页。
7. **设置 → 外观** — 深色 / 浅色 / 跟随系统。默认深色。
8. **设置 → 字体大小** — 档位立刻作用到终端预览行和会话页正文。
9. **不在线** — 收藏里的「归档席」是失联行，标「不在线」（不是空闲），点不开。

## 设计基线（对照评审）

- 默认人格：**终端深夜**。色板来自 `DesignTokens` `DarkPalette`：底 `#070B14`，列表 `#0D1422`，卡片 `#0F1725`，强调 **只有** `#77A6FF`（含发送钮、字号选中芯片），进行中青绿 `#4FD1C0` / `#5FDCC9`，未知 `#F0879F`。
- 浮层 / 列表 / 外壳同一套深色阶。
- 状态：进行中 = 青，空闲 = 灰，未知 = 粉。圆角一致。
- 路径副标题按「根段 + 末段」截断，比行尾省略好认。
- 功能键 + 输入条是一块深色控制台，圆角约 10–14dp。

## 不是什么

这不是真 xterm，也不是配对/入网。Kotlin 产品码在 `app/`，本目录只给观感评审。
