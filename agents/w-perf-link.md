# 二、拓扑已查清（这是硬事实，不要重新发现）

**Tailscale 不在系统里，它跑在 Shadowrocket 里。**

```
用户手机（tailnet 100.69.43.120）
   │  蜂窝数据（当前）/ 家里 WiFi（此前）
   ↓  WireGuard
Mac 上 /Applications/Shadowrocket.app 的包隧道扩展
   MacPacketTunnel.appex（pid 39476）持有 UDP *:41641 ← Tailscale 的 WG 数据端口
   同一进程还挂着多条到 82.21.81.136:443/8443 的 TCP —— 海外出口
   ↓
主机默认路由 = utun4 = Clash TUN（198.18.0.1，fake-ip-range 198.18.0.1/16）
   到 100.69.43.120 的主机路由 flags 含 WASCLONED —— 从默认路由克隆，
   即 Clash 配置里那条 route-exclude-address: 100.64.0.0/10 **没有生效**
   ↓
daemon agentmirrord（pid 70317）:9900
```

**为什么前面几轮全找不到**：没有 `tailscaled` 进程、没有 `100.x` 接口、
`/Applications/Tailscale.app` 已卸载 —— 因为 Tailscale 在用户态、在别人家的进程里。

其它已核事实：
- daemon 二进制编译于 08-13 00:25，`-host 192.168.31.116`，**无 TS_AUTHKEY，tsnet 关闭**
- ZeroTier 也在跑（主机 10.202.81.20），但蜂窝下 ICMP 100% 丢，用户判它不如 TS 稳
- App 产品代码 = v6 基线（`9653be07f`）逐字节零差异
