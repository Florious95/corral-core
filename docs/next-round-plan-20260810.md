## §3 自决点（用户授权我定，以下为已定口径）

### 3.1 外骨骼标注标准 v1（Go 注释标签 / Kotlin 同名 KDoc 标签）

```
@contract            标记本符号有契约（无契约的符号不必标）
@pre   / @post       前置 / 后置条件；无则显式写 none，不许省略
@inv                 不变量（类型 / 结构体 / 类级）
@err                 错误语义：返回什么错、什么条件下返回
@consumes / @produces 跨包契约方向，供架构维基现算依赖图
```

> 不套用任何 Rust 工程的既有标注标准——本工程是 Go + Kotlin 的全新语言面，标准从零定。

### 3.3 静态分析
本轮接：`go vet`（已有）+ **staticcheck**（BSD-3，许可兼容）+ **Android Lint**（AGP 自带，零新依赖）。
**detekt 不引**（需加插件、收益与 Lint 重叠）。三者接进 gate 对应面。
**并把 gate 加进每一条 acceptance 的收口位**——实测 gate 最后一次运行是 2026-08-09 18:47，
整整一天的改动没过过门，这是"隐含问题从不被发现"的直接原因。

**一包一席，注释＋契约一次做完**；18 包分批，每批 4–5 席；**同文件零并发**。
每批收口时校准 gate 的用例数棘轮，不绕过它。
