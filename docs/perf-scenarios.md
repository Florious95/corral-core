## 方法学（否则数字没意义）

1. **分位数**：每项出 p50 / p95 / p99 + max，不只看均值；样本量与采样窗口写进基线。
2. **基线 + 棘轮**：数字进 gate，只准变好不准变坏；超门限 `exit` 非 0 并打印实测 vs 门限。
   首版门限依 2026-08-10 基线定（约 3 倍余量），新场景跑出基线后照同法定。
3. **阳性对照**：每次测量配一个必然非空的对照（如故意注入 500ms 延迟必须被测出来），
   防止"没测到"被当成"很快"——这是 taskbook-orchestration skill 的不变量之一，本工程此前未做。

## 执行通道分工

- **A / B / C / E / F 组**：模拟器 + 隔离 daemon 上全测。
- **D1（tailnet 对比）**：走 API / instrumentation 路径。
- **F4 耗电、真实相机**：真机，交付 APK 后由用户验。
