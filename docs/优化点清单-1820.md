2. Esc Esc 回退：CLI 侧撤回的输入必须回显；已出现的文本手机端必须能删。
3. 输入框单行难编辑 → 点击后膨胀为多行。
4. 附件与发送按钮收进输入框内部，样式参考成熟 Agent APP。
