### 1.2 OpenAI Codex App 核心视觉基因：精准工程、代码至上（Precision Engineering & IDE Elegance）

1. **代码与工具调用卡片（ToolCallCard）的高级感**：
   - 绝非普通系统自带的灰色多行文本框，而是带有**现代化代码编辑器的微质感**；
   - 头部（Header）：精致的小图标（如终端 `bash`、文件 `file`、差异 `diff`）+ 等宽字体命令摘要 + 微型状态胶囊（如 `42ms`、`exit 0`）；
   - 交互：展开时内容高度自然生长，折叠时平滑收起，带有自然的阻尼感；
   - 代码区域：深浅模式下自带微深度背景（如深色 `#16161E`、浅色 `#F5F6F8`），代码语法高亮清晰锐利。

2. **斜杠自动补全（Slash Autocomplete Sheet `/`）的浮层质感**：
   - 用户在悬浮输入框键入 `/` 时，上方**非阻塞式升起一个半透明液态玻璃菜单**；
   - 菜单项包含：左侧微图标（如 `/compact` 压缩、`/clear` 清屏、`/help` 帮助）+ 命令名称高亮 + 浅灰简要说明；
   - 选中高亮带有细腻的圆角微光底色，点击后平滑填充并收起。

## 2. 视觉反面教材（上一轮被严厉驳回的致命教训）

为了让高级模型绝对不重蹈覆辙，牢记上一轮被用户严厉驳回的视觉硬伤（见现场真实截图 `upload-20261005T021032-1000009304.jpg`）：

```text
│  创建失败：结构化连接中断，请重新连接                    │  <- 刺眼的大红字，生硬的居中报错
│                                                        │
│            ┌──────────┐      ┌──────────┐              │
│            │   取消   │      │   创建   │              │  <- 粗糙生硬的矩形黑白线框

└────────────────────────────────────────────────────────┘
```

### 规避原则：
- **禁止粗暴弹窗**：网络或通道未就绪时，采用**优雅的内联占位骨架屏（Skeleton Loading）**或轻柔的非阻塞式提示，绝不允许弹出红色大弹窗阻断用户；
- **禁止生硬矩形方块**：所有按键必须具备优雅的连续曲率圆角（Capsule 或 16-20dp Squircle），搭配细腻的微阴影与按压阻尼微动效；
- **禁止刺眼的高饱和原色撞色**：配色必须严格遵循 OkLab 感知色彩空间，与整体主题深浅自然融合。

## 3. 性能与交互设计自由度（授权高级模型全权裁定）

高级视觉模型（Claude Opus 5.5）在实现本套设计时，享有以下最高裁定权：

1. **自由决定排版律动**：气泡内边距（Padding 12-16dp）、行高（Line Height）、字阶（Type Scale 13-15sp）完全由设计师自由决定；
2. **自由决定动效物理参数**：展开折叠卡片的弹簧刚度（Stiffness）与阻尼比（Damping Ratio），斜杠浮层的位移与淡入淡出动画，均以达到 120fps 丝滑为唯一准则；
3. **自由决定液态玻璃光感**：毛玻璃模糊半径（15-25dp Blur）、边缘微反光高光线条粗细、背景微透明度（Alpha 0.65-0.85）完全自由调节。
