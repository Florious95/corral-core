# 模拟器手测（远程Agent安卓）

**为什么要有这条**：本工程反复发生「单测全绿、账本全绿、用户一点就红」。
2026-08-19 一天内两次：悬浮窗三格全绿而真机全白；收藏 `t.fav` 全绿而**点星星根本没反应**。
**单测验的是我们想到的那几件事，模拟器验的是「看起来对不对」。**

## 0. 前置

模拟器禁令 **2026-08-19 已由用户解除**（原话：「这次要模拟器调试通过」）。
起之前先看资源——当初禁它是因为 free 内存一度只剩 59MB、load 29：

```bash
uptime                      # load 高于 ~15 就别起
vm_stat | awk '/Pages free|Pages inactive/'
```

## 1. 起模拟器

```bash
~/Library/Android/sdk/emulator/emulator -list-avds
# agentmirror_geo_1260x2800 ← 与用户手机同几何，优先用这个
nohup ~/Library/Android/sdk/emulator/emulator -avd agentmirror_geo_1260x2800 \
      -no-snapshot-load -no-boot-anim > /tmp/emu.log 2>&1 &
```

⚠️ **`adb` 不在 PATH**，一律用全路径：

```bash
export ADB=~/Library/Android/sdk/platform-tools/adb
$ADB shell getprop sys.boot_completed   # 1 = 起好了（约 20 秒）
```

## 2. 让 App 连上本机 daemon —— 三个坑全在这

```bash
$ADB reverse tcp:9900 tcp:9900          # ← 必须。10.0.2.2 走不通（被 macOS 防火墙拦）
```

**坑一：地址必须带 `/ws`。** 服务端只在 `mux.HandleFunc("/ws", …)` 上挂 WS，
而 App **不会自己补路径**（真机走扫码，二维码里带全路径，所以真机不暴露这个坑）。
填 `ws://127.0.0.1:9900` 会报「服务端地址不可达」，正确的是 **`ws://127.0.0.1:9900/ws`**。

**坑二：token 别打屏。** token 在 `~/Library/Application Support/agentmirror/token`。
取到变量里、不回显：

```bash
TOKEN=$(tr -d '\n\r' < ~/Library/Application\ Support/agentmirror/token)
```

🔴 **输入法候选栏会把 token 明文显示出来**（2026-08-19 实发，已上报）。
`input text` 之后**必须先关输入法再截图**。

**坑三：关输入法用 ESC(111)，不要用 BACK(4)。**
在配对页按 BACK 会**直接把 App 退到桌面**，前面填的全白填。

```bash
$ADB shell input keyevent 111    # ESC：收输入法，留在当前页
```

## 3. 手测路径与坐标

截图读回来是 **900x2000**，而设备是 **1260x2800** ⇒ **看到的坐标 ×1.4 才是 tap 坐标**。

```bash
$ADB exec-out screencap -p > /tmp/s.png    # 然后用 Read 工具看
```

🔴 **不许盲点**。每一步截图确认再点——盲点会点进别的会话、或把 App 退出去，
然后你会对着一张错误的截图分析半天（2026-08-19 实发三次）。

已知稳定坐标（1260x2800，仅供起手，仍要截图核对）：


## 4. 每次必看的检查单

按这个顺序走一遍，**每条截图留证**：

1. **一级菜单**：只出现含白名单 CLI 的工作区（Claude/Codex/Copilot/Grok/Cursor，契约 068）。
2. **二级菜单**：状态徽章 `进行中`/`空闲` 正确；**「未知」必须极少**；空心星星在状态左边。
3. **点星星** ⇒ 星星变实心 ⇒ 左栏收藏出现该会话 ⇒ 点它能直接进会话。
4. **三级终端**：中文/中英混排不乱码不错位。
5. **右上角「查看」悬浮窗**：无裸控制序列；**无横向截断**；只有会话树（⛔ 不含 choose-tree 预览区）；
   无大片空白；转圈动效在动。
6. **退出悬浮窗**：点面板外区域即关。

## 5. 判读纪律

- **App 对 logcat 几乎不写日志**，`adb logcat` 里找不到它的东西是正常的，不代表没跑。
  要看它的诊断日志走 设置 → 查看/导出诊断日志。
- **看到红字先看是哪一侧的版本**：新服务端会指名字段（如
  `overlay_subscribe socket must be non-empty`），旧服务端一律 `malformed frame`。
  报错文案变了不等于缺陷变了。
- **`nc host port && echo OK` 不是可用的连通性判据**（连不上也可能返回 0）。
  要用真实请求，并且**配一个必定失败的对照端口**，两边读数不同才作数。
